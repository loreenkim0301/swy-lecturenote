생성형 AI와 문서 작성 개요

모두 같은 ChatGPT 화면과 모델로 맞추고, 기존 방식과 AI 활용 방식을 비교해요. 마지막으로 AI에게 역할·맥락·작업·형식 4요소로 요청하는 법을 익혀요.

1-1. 시작 전: ChatGPT 화면 살펴보고 맞추기

실습을 시작하기 전에 자주 쓰는 곳을 확인하고 모두 같은 설정으로 맞춰요. 설정이 다르면 같은 프롬프트를 보내도 답의 모양이 달라져요.

위치이름하는 일
위쪽 가운데[Chat] / [Work]오늘은 [Chat]에서 실습해요. [Work]는 긴 작업을 맡기는 별도 화면이에요.
가운데입력창프롬프트를 붙여 넣고 Enter로 보내요. 줄을 바꿀 때는 Shift+Enter를 눌러요.
입력창 왼쪽[+][사진 및 파일 추가]로 파일을 올리고, [웹 검색]을 켜요.
입력창 오른쪽Instant모델과 추론 수준이 보여요. 오늘은 Instant로 맞춰요.
오른쪽 위임시 채팅기록에 남지 않는 대화를 열어요. 맨 아래 참고사항에서 다시 봐요.

모델과 추론 수준 맞추기

입력창 오른쪽 Instant를 눌러요. 작은 창에 추론 수준 슬라이더가 보여요. 슬라이더가 맨 왼쪽(Instant)에 있는지 확인해요.
창 위쪽 글자(Instant ›)를 누르면 모델 목록이 열려요. GPT-6에 체크가 되어 있는지 확인해요.
프로젝트 안에서는 모델 표시가 다를 수 있어요. 세션 3에서 프로젝트를 열면 입력창 오른쪽에 5.6 Instant처럼 다른 모델이 보일 수 있어요. 새 대화를 열 때마다 입력창 오른쪽 표시를 확인해요.

1-2. 기존 문서 작성 vs AI 활용 비교

같은 보고서를 만들 때 일하는 순서가 어떻게 달라지는지 비교해 봐요.

단계기존 방식AI 활용 방식사람이 꼭 할 일
자료 조사검색창에 여러 번 검색하고 자료를 직접 모아요[웹 검색]이 여러 출처를 찾아 요약하고 링크를 달아요출처를 열어 숫자와 날짜가 맞는지 확인
자료 읽기긴 PDF·한글 파일을 처음부터 읽어요파일을 올리면 핵심을 몇 줄로 요약해요요약의 숫자가 원문과 같은지 대조
구성·문체예전 보고서를 열어 목차와 문체를 베껴요Projects에 지침을 고정해 두면 같은 문체로 써요우리 기관 서식과 독자에 맞는지 판단
데이터 정리함수와 피벗을 직접 만들어요말로 요청하면 표와 차트를 만들어요기준값과 대조해 계산이 맞는지 확인
검토선배나 팀장이 읽고 빨간 펜출처 확인과 일관성 점검을 요청해요최종 승인과 책임
관리자에게 달라지는 일
AI가 초안을 빠르게 만들수록 관리자의 일은 두 가지로 모여요. 무엇을, 누구에게, 왜 쓰는지 정하는 일과 결과가 맞는지 확인하고 승인하는 일이에요. 팀원이 AI로 만든 보고서를 받으면 "출처는 어디인가요?", "이 숫자는 어떻게 계산했나요?", "AI가 쓴 부분 중 직접 고친 곳은 어디인가요?"를 물어보세요.

보안·개인정보(PII) 주의사항

개인정보(PII)는 이름, 연락처, 주민등록번호처럼 특정 사람을 알아볼 수 있는 정보예요. AI에 올리기 전에 아래 네 가지를 지켜요.

  1. 기관 보안 기준에서 쓸 수 있는 도구와 올릴 수 있는 자료의 범위를 먼저 확인해요.
  2. 이름·연락처·주민등록번호·계좌번호 같은 개인정보는 지우거나 가상 값으로 바꿔요.
  3. 공개 전 내부 문서(예산안, 인사 자료 등)는 올리지 않아요.
  4. 업무 자료를 다루는 프로젝트는 [프로젝트 전용 메모리]로 만들어요. (3-2)
