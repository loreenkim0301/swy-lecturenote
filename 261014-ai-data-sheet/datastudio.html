SESSION 6 · 리포트 자동화 (2) · 예시

데이터를 바꿔 끼워도 다시 쓰는
데이터 스튜디오 자동 보고서

ChatGPT가 정리한 결과 파일을 구글 시트에 넣고, 그 시트에 연결한 데이터 스튜디오 보고서를 매달 그대로 다시 쓰는 방법이에요. 교안 세션 6의 리포트 지시 프롬프트 다음 단계예요.

전체 흐름

  1. ChatGPT6-1 지시문으로 정리한 결과를 CSV 파일로 받기
  2. 다운로드파일 카드에서 CSV 내려받기
  3. 구글 시트정해 둔 시트의 data 탭 내용을 새 파일로 덮어쓰기
  4. 데이터 스튜디오같은 보고서를 열면 새 데이터로 다시 계산

핵심은 보고서가 "파일"이 아니라 "시트의 data 탭"을 보고 있다는 점이에요. 탭의 자리와 열 구성만 그대로면, 안에 든 데이터를 바꿔 끼워도 보고서는 다시 만들 필요가 없어요.

바꿔 끼워도 깨지지 않게 하는 규칙 4가지

규칙이유
① 시트 파일과 data 탭은 그대로 두고 내용만 바꿔요새 시트 파일을 만들거나 탭을 지우고 새로 만들면 보고서와의 연결이 끊겨요.
② 1행의 열 이름과 순서를 매달 똑같이 해요보고서의 차트는 열 이름(필드)을 기준으로 그려져요. 이름이 바뀌면 그 차트가 오류를 내요.
③ 값의 형식을 고정해요날짜는 2026-07-01, 금액·수량은 숫자만(원·쉼표 없이), 집계대상은 Y/N. 형식이 섞이면 합계나 기간 필터가 틀어져요.
④ 합계·비율 계산은 보고서에서 해요시트에는 행 단위 데이터만 두고, 보고서에서 "집계대상 = Y" 필터와 합계를 걸어 두면 데이터만 바꿔도 숫자가 다시 계산돼요.

고정할 열 구성 (예시 데이터 기준)

예시 파일 orders_clean.csv는 실습 파일 orders_raw.csv를 3-1 규칙서대로 정리한 120행이에요. 1행은 아래 13개 열이에요.

주문번호,주문일,월,지역,채널,담당자,상품코드,수량,단가,금액,결제상태,집계대상,비고

6-1에서 받은 지시문의 형식 줄에 아래 문장을 덧붙이면, ChatGPT가 매달 같은 모양의 파일을 만들어 줘요.

형식: (기존 내용에 이어서) 정리한 행 단위 데이터를 CSV 파일로도 만들어 줘. 열은 주문번호, 주문일, 월, 지역, 채널, 담당자, 상품코드, 수량, 단가, 금액, 결제상태, 집계대상, 비고 순서 그대로 쓰고, 주문일은 YYYY-MM-DD, 월은 YYYY-MM, 수량·단가·금액은 숫자만, 집계대상은 Y 또는 N으로 적어 줘.
확인 항목예시 데이터의 기준값 (교안 3-2와 같음)
행 수120
결제상태별 건수결제완료 103 / 취소 11 / 환불 6
집계대상 = Y97건
집계대상 = Y의 금액 합계4,357,000원

처음 한 번: 시트와 보고서 연결하기

  1. 구글 시트를 새로 만들고, 탭 이름을 data로 바꿔요. 예시 CSV를 가져와 data 탭에 넣어요.
  2. 데이터 스튜디오에서 빈 보고서를 만들고, 데이터 추가에서 Google Sheets → 방금 만든 시트 → data 탭을 고르면 연결돼요.
  3. 보고서에 아래 구성요소를 넣어요.
구성요소측정기준(무엇별)측정항목(무엇을)필터
스코어카드: 매출 합계없음금액 (합계)집계대상 = Y
스코어카드: 집계 대상 건수없음Record Count집계대상 = Y
막대 차트: 지역별 매출지역금액 (합계)집계대상 = Y
표: 월별·채널별 매출월, 채널금액 (합계)집계대상 = Y
표: 검토 필요 목록주문번호, 비고수량비고에 값이 있는 행
필터 "집계대상 = Y"는 보고서 전체에 한 번만 걸어 두면 편해요. 검토 필요 목록 표에는 걸지 말고 따로 필터를 줘요.

다음 달부터: 데이터만 바꿔 끼우기

  1. 새 달 원본 파일과 저장해 둔 지시문으로 ChatGPT에게 정리를 맡기고, 결과 CSV를 내려받아요.
  2. 검증용 요약(행 수, 집계 대상 건수, 매출 합계)을 먼저 확인해요. 숫자가 이상하면 시트에 넣기 전에 멈춰요.
  3. 구글 시트 data 탭을 열고, 기존 내용을 지운 뒤 새 CSV 내용을 A1부터 붙여 넣어요. 탭은 지우지 않아요.
  4. 데이터 스튜디오 보고서를 다시 열어 숫자가 새 달 기준으로 바뀌었는지, 스코어카드 합계가 ChatGPT 검증용 요약과 같은지 확인해요.
이럴 때 차트가 깨져요: 열 이름을 바꿨을 때(예: 금액 → 매출액), 새 시트 파일에 붙여 넣었을 때, 금액에 "원"이나 쉼표가 들어갔을 때. 이때는 파일을 고쳐 다시 붙여 넣고 보고서를 새로 만들지 않아요.
예시 데이터는 교안 실습 파일을 정리한 것이며 실제 회사 데이터가 아니에요. 화면 이름은 2026년 10월 기준이고, 데이터 스튜디오는 이전 이름이 Looker Studio예요.
