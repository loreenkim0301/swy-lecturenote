도구 지도: 세 기준으로 비교하기

왜 하나?바이브코딩 도구는 계속 새로 나와요. 도구 이름 대신 기준으로 보면, 새 도구도 바로 비교할 수 있어요.

개념1-1. 개념

세 기준이란?

① 원본 코드가 어디에 저장되나(내 컴퓨터·도구 회사 서버) ② 어디서 실행되나(브라우저·클라우드·내 컴퓨터) ③ 어디까지 대신 해 주나(화면만·DB까지·배포까지)예요.

왜 기준으로 보나요?

바이브코딩 도구는 계속 새로 나와요. 이름 대신 세 기준으로 보면, 새 도구가 나와도 아는 도구 옆에 놓고 비교할 수 있어요. 가격과 무료 범위는 자주 바뀌어서, 공식 페이지에서 확인한 날짜를 함께 적어요.

볼트로 Hello 페이지 만들기

왜 하나?코드 없이 한 줄 요청으로 화면이 만들어지는 것을 직접 봐요.

개념2-1. 개념

볼트란?

볼트는 말로 요청하면 웹 앱을 만들어 주는 AI 앱 빌더예요. 화면 만들기, 데이터베이스, 공개(배포)를 한곳에서 할 수 있어요.

어떤 문제를 해결하나요?

코드를 몰라도 원하는 것을 말하고, 대화로 고칠 수 있어요. 도움말은 볼트가 '기술적인 걸림돌을 없애 준다'고 설명해요. 수요일에는 파일을 내려받아 깃헙에 올려야 했지만, 볼트는 만들기부터 공개까지 한 화면에서 해요.

조심할 점

볼트는 요청할 때마다 토큰을 써요. 무료 플랜은 하루 30만(300K) 토큰, 한 달 100만 토큰까지이고, 남은 하루 양은 다음 날로 넘어가지 않아요. 오늘 실습(Hello 페이지 + 데이터베이스 저장)은 강사 계정에서 약 16만 토큰을 썼어요(2026-11-05 기준). 그래서 프롬프트는 한 줄로 짧게 쓰고, 고칠 것은 모아서 한 번에 보내요.

써 볼까요?

Hello 문구와 이름 입력칸 하나, 저장 버튼만 있는 페이지를 만들어요. 디자인은 최소로 해요.

출처: 볼트 공식 도움말 Introduction to Bolt · Tokens (2026.11.05 확인)

따라 하기2-2. 따라 하기

  2. 가운데 입력창에 아래 한 줄을 넣고 보내요.

    프롬프트 3 · 복사해서 볼트 입력창에 붙여 넣으세요
    Hello 문구와 이름 입력칸 1개, 저장 버튼만 있는 페이지를 최소한의 디자인으로 만들어 줘.

  3. 오른쪽 미리보기에 Hello, 이름 입력칸, 저장 버튼이 보이는지 확인해요.

막히면2-3. 막히면

이렇게 보이면이렇게 해요
볼트가 데이터베이스 저장까지 한 번에 하겠다고 해요'데이터베이스 저장은 빼고 화면만 먼저 만들어 줘'라고 한 줄로 답해요. 저장은 다음 세션에서 따로 연결해요.
토큰이 모자란다고 나와요오늘 쓸 수 있는 무료 양을 다 썼어요. 하루 양은 다음 날 다시 채워져요. 오늘은 강사 화면으로 따라와요.

SESSION 3 · 13:00–14:30 · 도구 실습

이름을 볼트 데이터베이스에 저장하기

왜 하나?수요일 브라우저 저장은 내 브라우저에만 남았어요. 오늘은 이름이 한곳에 쌓이게 해요.

개념3-1. 개념

볼트 데이터베이스란?

볼트 안에 들어 있는 데이터베이스예요. 모든 플랜에 들어 있고, 새 프로젝트에서 기본으로 쓰여요.

어떤 문제를 해결하나요?

브라우저 저장은 그 브라우저에서만 보였어요. 데이터베이스에 저장하면 누가 어디서 넣든 한곳에 모여요.

조심할 점

데이터베이스 연결은 화면 만들기보다 토큰을 더 써요. 강사 계정에서는 이 단계에만 약 9만 5천 토큰을 썼어요(2026-11-05 기준). 저장이 됐는지는 '저장되었습니다' 문구만 믿지 않고, 데이터베이스 화면을 열어 눈으로 확인해요.

써 볼까요?

이름을 넣고 저장을 누르면, 그 이름이 볼트 데이터베이스에 한 줄씩 쌓이게 해요.

출처: 볼트 공식 도움말 Supabase integration(볼트 기본 데이터베이스 안내 포함) (2026.11.05 확인)

따라 하기3-2. 따라 하기

  1. 볼트 대화창에 아래 한 줄을 보내요.

    프롬프트 4 · 복사해서 볼트 대화창에 붙여 넣으세요
    입력한 이름이 볼트 데이터베이스에 저장되게 연결해 줘.

  2. 미리보기 입력칸에 가상의 이름(예: 홍길동)을 넣고 저장을 눌러요.

  3. 위쪽 Database 버튼 → Tables → names를 눌러, 방금 넣은 이름이 한 줄 생겼는지 봐요.

막히면3-3. 막히면

이렇게 보이면이렇게 해요
표 목록에 names가 0 rows로 보여요표 이름(names)을 눌러 열어요. 강사 실행에서도 목록에는 0 rows로 보였고, 표를 열자 1줄이 보였어요. 그래도 없으면 Refresh를 눌러요.
'저장되었습니다'는 뜨는데 표에 없어요미리보기를 새로고침하고 다시 저장해요. 그래도 없으면 볼트에 '저장이 안 돼. 원인을 찾아 줘'라고 한 줄로 물어요.

개념4-1. 개념

Publish란?

볼트에서 만든 앱을 인터넷 주소로 공개하는 버튼이에요. 무료로 공개한 볼트 사이트에는 'Made in Bolt' 표시가 붙어요(볼트 공식 도움말).

어떤 문제를 해결하나요?

공개하면 휴대폰이나 다른 사람 컴퓨터에서도 같은 앱을 쓸 수 있어요. 어디서 넣든 이름은 같은 데이터베이스에 쌓여요.

조심할 점

공개한 주소는 누구나 열고 이름을 넣을 수 있어요. 실제 이름 대신 가상의 이름만 넣어요.

써 볼까요?

앱을 공개하고, 휴대폰에서 다른 가상 이름을 넣어 데이터베이스에 한 줄 더 쌓이는지 봐요.

따라 하기4-2. 따라 하기

  1. 오른쪽 위 Publish를 누르면 아래 창이 나와요. Public(공개)인지 보고 파란 Publish를 눌러 주소를 받아요.

  2. 공개가 끝나면 창에 주소(…bolt.host)와 Unpublish가 보여요. 주소 옆 복사 버튼으로 주소를 복사해요.

  3. 휴대폰으로 주소를 열고, 다른 가상 이름을 넣어 저장해요.

  4. 컴퓨터에서 Database → names를 다시 열어, 줄이 2개가 됐는지 봐요.
