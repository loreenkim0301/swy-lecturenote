도구 지도: 세 기준으로 비교하기

왜 하나?도구는 계속 새로 나와요. 이름 대신 기준으로 보면 새 도구도 바로 비교할 수 있어요.

개념1-1. 개념

도구 이름보다 중요한 건 세 가지예요. ① 원본 코드가 어디에 저장되나(내 컴퓨터·도구 회사 서버) ② 누가 실행하나(브라우저·클라우드·내 컴퓨터) ③ 어디까지 대신 해 주나(화면만·DB까지·배포까지). 이 세 기준을 쓰면 새 도구가 나와도 기존 도구 옆에 놓고 비교할 수 있어요. 오늘 아침에는 AI 초안으로 표를 만들고, 직접 써 본 볼트 줄은 오후 마지막 세션에서 고쳐요. 가격과 무료 범위는 자주 바뀌니 공식 페이지에서 확인한 날짜를 함께 적어요.

요청서로 볼트에서 첫 페이지 만들기

왜 하나?같은 요구사항을 다른 도구에 주면 결과가 달라요. 그 차이를 봐야 도구를 고르는 눈이 생겨요.

개념2-1. 개념

웹 빌더는 한 번에 많이 만들어서 한도를 빨리 써요. 그래서 PRD를 그대로 붙이지 않고 '이번에 만들 것 / 만들지 않을 것 / 데이터 / 예외'로 줄인 요청서로 바꿔 한 번에 정확히 요청해요. 볼트 사용량은 일별·월별 퍼센트 막대로 보이고, 정확한 숫자는 도움말에 나와 있지 않아서 화면에 보이는 값을 그대로 적어요(볼트 공식 도움말).

들어가는 길 · 볼트

https://bolt.new

처음이면 오른쪽 위 'Get Started'로 가입해요. 가운데 입력창에 요청서를 붙여 넣고 'Build now'를 눌러요. 입력창 아래에서 Website·App 같은 종류를 고를 수 있어요.

따라 하기2-2. 따라 하기

  1. 볼트에 로그인하고, 요청을 보내기 전에 남은 사용량을 확인해 사용량 기록표(오후 5번 세션)에 시각과 함께 적어요.

  2. 클로드에서 PRD를 볼트 요청서로 줄여요.

    프롬프트 3 · 복사해서 클로드에 붙여 넣으세요
    요청: 내 간단 PRD를 웹 빌더(볼트)에 한 번에 줄 요청서로 줄여 줘
내용: PRD: [개요: 연말 선물을 고르는 기존 고객이 혜택을 한곳에서 확인하고 사전 신청 / 핵심 기능: 혜택 보기, 사전 신청, 입력 검사, 중복 신청 막기, 마감 처리 / 예외: 연락처 형식 오류, 동의 안 함, 중복 신청, 12월 15일 마감] / 데이터 정의표: [입력: 이름·연락처·관심 선물 카테고리·동의 / 저장: 신청 내역+신청 시각 / 기본: 이벤트명·마감일·혜택 3가지·카테고리 목록]
형식: 표(이번에 만들 것 / 만들지 않을 것 / 데이터 / 예외 / 저장 방법) + 볼트에 붙여 넣을 요청 문장 한 덩어리. 저장 방법은 정하지 말고 '먼저 방법을 설명해 달라'고 써

  3. 볼트 첫 화면 가운데 입력창에 클로드가 만든 '볼트에 붙여 넣을 요청 문장'을 붙여 넣고 보내요.

  4. 오른쪽 미리보기에서 혜택 3가지·신청 폼·완료 안내가 있는지 보고, 요청서와 비교해 점검받아요.

개념3-1. 개념

왜 하나?'잘 되는 것 같다'로 끝내지 않고, 화요일에 쓴 성공·실패·예외 시나리오를 하나씩 실행해 확인해요.

개념4-1. 개념

기대 결과와 실제 결과를 나란히 적으면 무엇을 고쳐야 할지 바로 보여요. 다른 기기(휴대폰)에서 넣은 신청이 데이터 화면에 보이면, 어제 브라우저 저장의 한계를 넘은 거예요. 무료로 공개한 볼트 사이트에는 'Made in Bolt' 배지가 붙어요(볼트 공식 도움말).

따라 하기4-2. 따라 하기

  1. 볼트 오른쪽 위 Publish를 눌러 배포하고 주소를 받아요.

  2. 테스트 시나리오 표를 만들어요.

    프롬프트 8 · 복사해서 클로드에 붙여 넣으세요
    요청: 내 성공·실패·예외 시나리오를 배포본 테스트 시나리오 표로 바꿔 줘
내용: 시나리오: [성공 1 / 연락처 형식 오류 / 동의 안 함 / 중복 신청 / 마감 지남] / 확인할 기기: [휴대폰, 컴퓨터 크롬]
형식: 표(번호 / 행동 / 기대 결과 / 실제 결과 빈칸 / 통과 빈칸). 저장소에서 확인해야 하는 줄은 표시

  3. 휴대폰과 컴퓨터에서 표의 줄을 하나씩 실행하고 '실제 결과'와 통과(O·X)를 적어요. 저장소 확인 줄은 볼트 데이터 화면에서 봐요.

  4. X가 나온 줄은 수정 요청 문장을 받아 볼트에 넣고, 같은 줄을 다시 테스트해요.

형식: 볼트에 붙여 넣을 수정 요청 1개(바꿀 것·그대로 둘 것 포함) + 고친 뒤 다시 할 테스트
