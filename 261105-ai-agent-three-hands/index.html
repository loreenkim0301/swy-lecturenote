말만 하던 AI가 이제 브라우저를 누르고, 내 컴퓨터 파일을 고치고, 다른 앱과 이어져 일해요. 이 세 가지 손은 누가 먼저 만들었고, 언제 모두가 쓰게 됐을까요? 세 장면으로 나눠 따라가요.

개념0-1. 세 개의 손

손 ①

브라우저를 쥔 손

크롬 확장 프로그램으로 웹 페이지를 읽고 클릭·입력·스크롤해요. 내 옆에 앉아 마우스를 대신 잡는 비서와 같아요.

손 ②

컴퓨터를 쥔 손

화면을 보고 조작하거나, 허락받은 폴더의 파일을 직접 처리해요. 모니터를 보는 눈과 서류함 열쇠를 함께 가진 셈이에요.

손 ③

앱을 잇는 손

커넥터로 Gmail·슬랙 같은 앱과 연결해요. 어떤 기기든 꽂히는 만능 플러그와 같아요.

개념0-2. '누가 처음 만들었나'는 층마다 답이 달라요

원천 기술 하나, 만든 사람 한 명으로 답할 수 없어요. 세 기능은 모두 세 층으로 쌓여 있고, 층마다 주인공이 달라요.

장면 1

브라우저를 쥔 손

귀찮은 반복 테스트에서 시작해, AI가 내 크롬을 누르기까지 20년이 걸렸어요.

  1. 2004
    Selenium프로그램이 사람 대신 브라우저를 누르기 시작했어요.
  2. 2022.09
    Adept ACT-1AI가 크롬 확장 프로그램으로 직접 눌렀어요.
  3. 2024–2026
    빅테크 세 갈래Google·OpenAI·Anthropic이 서로 다른 길로 갔어요.

2004 · 시카고1-1. 시작은 AI가 아니라 귀찮은 테스트였어요

ThoughtWorks의 개발자 Jason Huggins는 사내 경비정산 웹앱을 만들고 있었어요. 기능을 고칠 때마다 같은 버튼을 손으로 눌러 확인해야 했어요.

그래서 브라우저를 대신 눌러 주는 프로그램을 만들었어요. 이것이 Selenium이에요. 처음에는 사내 도구였고, 나중에 오픈소스로 공개됐어요.

2007년에는 같은 회사의 Simon Stewart가 WebDriver를 만들었어요. 두 도구는 이후 하나로 합쳐졌어요.

이 장면의 의미 '프로그램이 브라우저를 조작한다'는 생각이 여기서 시작됐어요. 다만 Selenium은 사람이 짜 둔 순서대로만 눌러요.

출처: Selenium History (공식, 2026.11.05 확인)

2022.09.141-2. 18년 뒤, AI가 크롬 확장으로 직접 눌렀어요

AI 스타트업 Adept가 ACT-1을 공개했어요. AI 모델이 크롬 확장 프로그램을 통해 브라우저를 관찰하고, 클릭·입력·스크롤을 했어요.

Selenium (2004)

사람이 짠 순서대로만 눌러요.

→
Adept ACT-1 (2022)

AI가 화면을 보고 다음에 누를 곳을 스스로 골라요.

ACT-1은 시연 영상만 공개됐고, 모델과 코드는 공개되지 않았어요. '최초'라고 단정하지 말고 '확인된 가장 이른 공개 사례'라고 말해요.

출처: Adept 블로그 원문을 인용한 보도 (원문 미러, 언론 보도)

결말1-4. 결국 AI가 사람의 브라우저로 들어갔어요

OpenAI는 자체 브라우저 Atlas를 접고 크롬 확장으로 옮겨 갔다고 보도됐어요. Google은 크롬을 가진 회사라 브라우저 안에 바로 넣었어요. Anthropic은 처음부터 확장 프로그램 방식이었어요.

정리 새 브라우저로 사람을 옮기기는 어려워요. 세 회사 모두 결국 사람이 이미 쓰는 크롬 안에서 일하는 쪽을 택했어요.
장면 2

컴퓨터를 쥔 손

모니터를 보는 눈과 서류함 열쇠는 서로 다른 기술이에요.

개념2-1. 컴퓨터 유즈와 로컬 파일 권한은 달라요

컴퓨터 유즈

AI가 화면을 캡처해 보고 마우스·키보드를 움직여요. 모니터를 보고 손으로 조작하는 사람과 같아요.

어떤 앱이든 다룰 수 있지만 느리고, 잘못 누를 수 있어요.

vs
로컬 파일 권한

허락받은 폴더 안의 파일을 AI가 직접 읽고 고치고 만들어요. 서류함 열쇠를 받아 직접 정리하는 사람과 같아요.

빠르고 정확하지만, 허락한 폴더의 파일 일에만 쓸 수 있어요.

2024–20262-2. 개발자용 기능에서 책상 위로 왔어요

날짜회사무엇의미
2024.10.22Anthropic컴퓨터 유즈 공개 베타(개발자용 API)이 범주를 처음 연 순간이에요. Anthropic은 프런티어 모델 중 처음이라고 발표했어요
2025.01.23OpenAIOperator일반 사용자 제품으로 처음 나왔어요(미국 Pro, 원격 브라우저)
2025.10.07Google DeepMindGemini 2.5 Computer Use(API 미리보기)웹 브라우저에 맞춰져 있고, 컴퓨터 전체 조작은 아직이라고 밝혔어요
2026.01.12Anthropic클로드 코워크(Claude Cowork) 리서치 프리뷰비개발자가 허락한 폴더의 파일 일을 맡기게 됐어요(macOS, Max)

공식 확인: Gemini 2.5 Computer Use (2026.11.05 확인) / 언론 보도: Anthropic 컴퓨터 유즈, Operator, 클로드 코워크

결말2-3. '처음'도 대상에 따라 달라요

컴퓨터 유즈라는 범주는 Anthropic이 개발자용으로 먼저 열었어요. 일반 사용자에게 처음 보여 준 제품은 OpenAI Operator예요. 비개발자에게 내 컴퓨터 파일을 맡기게 한 대표 사례는 클로드 코워크예요.

OpenAI·Google의 같은 종류 로컬 파일 기능은 공식 문서로 확인하지 못해 넣지 않았어요. RPA(업무 자동화 소프트웨어)를 원조로 보는 견해도 있지만, 공식 출처로 확인하지 않아 다루지 않아요.
장면 3

앱을 잇는 손

회사마다 콘센트 모양이 달랐던 시절에서, 만능 플러그가 생기기까지예요.

20233-1. 처음엔 회사마다 플러그 모양이 달랐어요

날짜회사무엇한계
2023.03.23OpenAIChatGPT 플러그인 (Expedia·Slack·Zapier 등)OpenAI 전용 규격이에요

AI 앱이 N개, 도구가 M개라면 N×M개의 연결을 하나씩 따로 만들어야 했어요. 나라마다 콘센트가 달라 여행 때마다 어댑터를 사는 상황과 같아요.

Anthropic의 엔지니어 David Soria Parra와 Justin Spahr-Summers가 MCP를 만들었어요. Anthropic은 MCP를 처음부터 오픈 표준·오픈소스로 공개했어요.

결말3-4. 만든 회사만 쓰면 사내 규격이에요

개념은 ChatGPT 플러그인(2023)이 먼저였어요. 하지만 지금 커넥터가 실제로 올라타 있는 규격은 MCP(2024)예요.

정리 MCP를 표준으로 만든 건 기술이 아니라 경쟁사 OpenAI의 채택(2025.03)이었어요. 2025년 12월 리눅스재단 기증으로 특정 회사의 것이 아니게 됐어요.

'모두가 쓰게 된 시점'은 출시 대상 범위를 근거로 정했어요. 사용자 수로 확인한 것은 아니에요.

자주 받는 질문다 오픈소스에서 시작한 거 아닌가요?

아니에요. 처음부터 공개로 시작한 건 MCP 하나예요.
