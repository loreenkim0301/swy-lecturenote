SESSION 1 · 09:00–10:00

Colab과 친해지기

오늘 수업의 모든 실습은 Google Colab에서 해요. 처음 보는 도구라 낯설 수 있지만, 꼭 필요한 개념은 몇 가지뿐이에요. Colab이 무엇인지, 화면의 기본 단위가 어떤 역할을 하는지 알고 첫 코드를 실행해요.

1-1. Colab이란 무엇인가

Colab(정식 이름 Colaboratory)은 구글이 만든 온라인 코드 실행 노트예요. 원래 구글 리서치 팀이 연구자들을 위해 만들었고, 2017년에 일반 사용자에게 공개되었어요. 파이썬 코드를 내 컴퓨터가 아니라 구글의 서버에서 실행해 주기 때문에, 브라우저만 있으면 설치 없이 바로 코딩을 시작할 수 있어요. 구글 문서처럼 구글 드라이브에 자동 저장되고, 링크로 공유할 수도 있어요.

항목내용
만든 곳Google (Google Research)
요금기본 무료. 구글 계정만 있으면 쓸 수 있어요. 더 빠른 컴퓨터 자원이 필요한 사람을 위한 유료 요금제(Colab Pro 등)가 있고, 2026년 9월 22일부터는 Google AI 요금제 구독자에게도 Colab 프리미엄 혜택이 포함되기 시작했어요. 이 수업은 무료로 충분해요.

1-2. 노트, 코드 셀, 텍스트 셀은 무슨 역할인가

Colab 파일 하나를 노트(노트북)라고 불러요. 노트는 칸(셀)들이 위에서 아래로 쌓인 문서예요. 칸에는 두 종류가 있어요. 컴퓨터에게 시키는 일을 적는 코드 셀, 사람이 읽을 설명을 적는 텍스트 셀이에요. 이렇게 나눠 두면 코드와 그 코드의 의도·결과 해석을 한 문서에 함께 남길 수 있어요. 나중에 내가 다시 보거나 동료에게 공유했을 때 "무엇을 왜 했는지"가 함께 전달돼요.

구성 요소역할왜 필요한가
노트코드, 설명, 실행 결과를 한 파일에 담는 문서작업 과정 전체를 하나의 기록으로 남기고 공유할 수 있어요. 기획서 한 장에 근거와 결론이 같이 있는 것과 비슷해요.
코드 셀컴퓨터에게 시킬 일을 적는 칸. 실행하면 결과가 칸 바로 아래에 나타나요.한 칸씩 실행하고 확인할 수 있어서, 어디서 문제가 생겼는지 찾기 쉬워요.
텍스트 셀사람이 읽는 메모·설명을 적는 칸. 실행되지 않아요.코드의 의도, 결과 해석, 다음 할 일을 기록해요. 과제 정리도 여기에 해요.
런타임코드를 실제로 실행해 주는 구글 서버와의 연결오래 쓰지 않으면 연결이 끊기고 기억하던 값이 사라져요. 그럴 때는 위에서부터 다시 실행하면 돼요.
기본 조작은 두 가지만 기억해요
코드 셀을 실행할 때는 셀 왼쪽의 ▶ 버튼을 누르거나 Shift+Enter를 눌러요. 노트를 공유할 때는 오른쪽 위 [공유]를 눌러요.

2-2. AI의 답을 믿기 전에 알아야 할 것

Gemini는 지금 노트의 코드와 오류를 직접 보고 답할 수 있다는 장점이 있어요. 다만 같은 질문에도 답이 매번 달라질 수 있다는 점을 미리 알아 둬요.

  • 답이 다를 수 있는 이유: Gemini가 생성형 AI이기 때문이에요. 생성형 AI는 정해진 정답을 찾아오는 것이 아니라, 그때그때 그럴듯한 답을 새로 만들어 내요. 그래서 같은 질문을 다시 해도 답이 달라질 수 있어요.
  • AI도 실수해요: 문법은 맞지만 결과가 틀린 코드를 자신 있게 내놓기도 해요. 그래서 AI가 준 코드는 반드시 실행해서 결과를 직접 확인해요.
  • 같은 대화 안에서 검증하면 AI는 자기 답을 옹호하는 경향이 있어요: 코드를 만들어 준 그 대화창에 "이거 맞아?"라고 물으면, AI는 앞서 자신이 한 답에 맞춰 "맞다"고 하기 쉬워요. 검토를 맡길 때는 새 채팅을 열어 물어봐요.
검증 원칙: 최종 판단은 AI가 아니라 실행 결과와 내가 기대한 값을 비교해서 내려요.

프로그래밍은 어떻게 동작하나

프로그램이 움직이는 기본 원리와, 앞으로 모든 실습 코드에 나오는 주석이 무엇인지 먼저 이해해요. 그다음 입력·처리·출력이 있는 짧은 코드를 실행하고, 오늘 쓰는 언어 파이썬이 어떤 언어인지 알아봐요.

3-1. 입력, 처리, 출력

프로그래밍은 컴퓨터에게 할 일을 순서대로 적어 주는 일이에요. 컴퓨터는 눈치를 보거나 빠진 부분을 알아서 채우지 않고, 적힌 그대로 위에서 아래로 한 줄씩 실행해요. 거의 모든 프로그램은 무언가를 받아서(입력), 정해진 규칙대로 계산하고(처리), 결과를 보여 주는(출력) 구조로 되어 있어요. 키오스크에서 메뉴를 고르면(입력) 금액이 계산되고(처리) 영수증이 나오는(출력) 것과 같아요.

우리가 쓰는 코드는 사람이 읽을 수 있는 글이에요. 이 글을 컴퓨터가 알아듣도록 읽고 실행해 주는 프로그램을 해석기라고 불러요. Colab은 구글 서버에 이 해석기가 이미 준비되어 있는 환경이에요.

1입력메뉴를 고르고 수량을 넣어요
2처리가격 × 수량, 할인 규칙을 계산해요
3출력결제 금액을 화면에 보여 줘요

3-2. 주석이란 무엇인가

주석은 코드 안에 적어 두는 사람을 위한 메모예요. 파이썬에서는 # 기호 뒤에 쓴 내용이 주석이 되고, 컴퓨터는 실행할 때 이 부분을 완전히 무시해요. 그래서 주석에는 "이 줄이 무슨 일을 하는지", "왜 이렇게 했는지"를 한국어로 자유롭게 적을 수 있어요. 코드는 나중에 나 자신이나 동료가 다시 읽게 되므로, 주석은 기획서의 각주처럼 의도를 남기는 역할을 해요.

구분예시컴퓨터가 실행하나?
코드price = 15000실행해요
주석# 상품 가격을 저장무시해요
코드 + 주석price = 15000 # 상품 가격을 저장# 앞까지만 실행해요
이 교안의 모든 실습 코드에는 줄마다 주석으로 설명을 달아 두었어요
주석은 그대로 복사해 붙여 넣어도 실행에 영향을 주지 않아요. AI가 써 준 코드를 이해할 때도 "줄마다 주석을 달아 줘"라고 요청하면 큰 도움이 돼요.

실습 3-2. 주석은 정말 무시될까?

실습 노트에 새 코드 셀을 추가하고, 아래 코드를 복사해 붙여 넣은 뒤 Shift+Enter로 실행해요.

방금 무슨 일이 일어났나
출력은 한 줄뿐이에요. 셋째 줄은 print가 있지만 맨 앞에 #이 붙어 통째로 주석이 되었기 때문에 실행되지 않았어요.

더 해 보기 셋째 줄 맨 앞의 #을 지우고 다시 실행해요.

  • #을 지운 뒤에는 "이 줄은 실행될까요?"까지 두 줄이 나왔나요?

3-3. 실습: 입력, 처리, 출력 코드 실행하기

실습 입력 → 처리 → 출력이 있는 짧은 코드부터 시작해, 가게 메뉴판과 주문 받기까지 만들어 봐요. 모든 캡처는 2026-10-29 강사 노트에서 직접 실행한 화면이에요.

STEP 1. 실행하고 결과 보기

[+ 코드]로 새 셀을 만들고 아래 코드를 붙여 넣어 Shift+Enter (Mac shift+return)로 실행해요.
셀 아래 생긴 입력 칸을 클릭하고 10000을 입력한 뒤 Enter를 눌러요.
코드 · 복사해서 Colab 코드 셀에 붙여 넣으세요
price = int(input("상품 가격(원): "))   # 입력: 숫자를 받아 price에 저장
total = price * 1.1                    # 처리: 부가세 10%를 더한 금액 계산
print("결제 금액:", int(total), "원")   # 출력: 소수점을 버리고 화면에 표시

방금 무슨 일이 일어났나
첫째 줄에서 입력받은 10000이 price에 저장되고(입력), 둘째 줄에서 1.1을 곱해 total을 계산하고(처리), 셋째 줄에서 결과를 화면에 보여 줬어요(출력). 순서가 곧 로직이에요. 같은 셀을 다시 실행해 25000을 넣으면 결제 금액: 27500 원이 나와요.

⚠ 헷갈리기 쉬운 곳 · 입력 칸
  • 입력 칸이 떠 있는 동안 셀은 계속 실행 중이에요(셀 왼쪽 버튼이 빙글빙글 돌아요). 이때 다른 셀을 실행하면 그 셀은 기다려요. 값을 넣고 Enter를 누르면 이어서 실행돼요.
  • 10,000처럼 쉼표나 글자를 넣으면 ValueError가 나요. 숫자만 입력해요.

변수 개수와 print 개수를 바꿔 가며 결과가 어떻게 달라지는지 봐요. 각각 새 셀에 붙여 넣고 실행해요.

STEP 3. 메뉴판 만들기

채소가게 직원이 양파·토마토·감자의 정가를 입력하면, 고객에게는 부가세 10%를 포함한 금액만 보이는 메뉴판을 만들어요.

새 셀에 아래 코드를 붙여 넣고 실행해요.
입력 칸이 차례로 3번 나와요. 양파 2000, 토마토 3000, 감자 1500을 하나씩 입력해요.
메뉴판이 나오면 가게 이름이나 안내 문구(예: "오늘 들어온 신선 채소예요")를 print("...") 줄로 직접 추가해 다시 실행해 봐요.

⚠ 헷갈리기 쉬운 곳 · 셀 사이의 변수

  • 런타임이 끊기면(오래 쉬거나 다시 열면) 기억하던 변수가 모두 사라져요. 그때는 아래 셀만 실행하면 NameError가 나요.

3-4. 파이썬은 무엇인가

파이썬은 1991년 네덜란드의 프로그래머 귀도 반 로섬이 발표한 프로그래밍 언어예요. 지금도 계속 발전하고 있어서, 2026년 10월 기준 최신 버전은 파이썬 3.15예요(3.15.0 정식판 10월 9일, 3.15.1 10월 21일 공개). 문법이 영어 문장에 가깝고 간결해서 처음 배우는 사람에게 가장 많이 권하는 언어 중 하나이고, 동시에 데이터 분석, 업무 자동화, 인공지능 개발 같은 실무 현장에서도 널리 쓰여요. 쉽게 시작할 수 있으면서 실무에서도 바로 쓰인다는 점이 파이썬의 가장 큰 특징이에요.

③ 프론트엔드 + 백엔드 헬로 웹

③에서 처음 보는 문법 코드가 길지만, 지금은 "서버가 이런 모양이구나"만 보면 돼요. 그대로 복사해 실행해요.

새 문법·함수뜻
Flask(__name__)웹 서버 앱을 만들어 app에 저장해요. __name__은 파이썬이 정해 둔 이름이라 그대로 써요.
def 이름(): / return함수를 만들어요. def로 이름을 붙이고, 아래에 들여쓴 줄이 할 일이에요. return 뒤의 값을 결과로 돌려줘요.
@app.route("/주소")바로 아래 함수를 "이 주소로 요청이 오면 실행할 함수"로 등록하는 표시예요. "/"는 첫 화면, "/api/hello"는 버튼이 요청하는 곳이에요.
jsonify(message=...)파이썬 값을 브라우저가 읽을 수 있는 데이터(JSON) 모양으로 바꿔 보내요.
threading.Thread(...).start()서버를 뒤에서 따로 돌려요. 그래야 셀이 멈추지 않고 다음 줄이 실행돼요.
output.serve_kernel_port_as_iframe(8000)Colab 런타임의 8000번 문(포트)에서 열린 서버 화면을 결과 칸에 띄워요.
fetch('api/hello')HTML 안의 자바스크립트예요. 버튼을 누르면 서버의 /api/hello 주소로 요청을 보내요.
코드 · 새 셀에 붙여 넣고 실행
from flask import Flask, jsonify   # 웹 서버(백엔드) 도구
import threading

app = Flask(__name__)

@app.route("/")                 # 프론트엔드: 브라우저에 보낼 화면(HTML)
def home():
    return """
    <h1>헬로 웹!</h1>
    <button onclick="fetch('api/hello').then(r => r.json()).then(d => msg.innerText = d.message)">서버에 물어보기</button>
    <p id="msg"></p>
    """

@app.route("/api/hello")        # 백엔드: 버튼을 누르면 파이썬이 답하는 곳
def hello():
    return jsonify(message="파이썬 서버가 보낸 인사: 안녕!")

threading.Thread(target=lambda: app.run(port=8000), daemon=True).start()   # 서버를 뒤에서 실행

from google.colab import output
output.serve_kernel_port_as_iframe(8000)   # 런타임의 8000번 포트 화면을 결과 칸에 표시

번호무엇규칙과 주의
①변수 이름영어로 시작하고 띄어쓰기 없이 써요. 두 단어면 player_name처럼 밑줄로 이어요. 대문자와 소문자는 다른 이름이에요.
②= (저장)"같다"가 아니라 오른쪽 값을 왼쪽 이름에 저장하라는 뜻이에요. 양옆 띄어쓰기는 읽기 좋게 넣는 것이고, 없어도 동작해요.
③따옴표글자는 따옴표로 감싸요. 여는 따옴표와 닫는 따옴표가 짝이 맞아야 해요. 하나라도 빠지면 SyntaxError예요(1-6 디버깅).
④# 주석# 뒤는 사람을 위한 메모라 실행되지 않아요(3-2).
⑤숫자숫자는 따옴표 없이, 쉼표 없이 써요. 1,000으로 쓰면 오류는 안 나지만 1과 0 두 개의 값이 묶인 전혀 다른 값이 돼요.
⑥계산해서 다시 저장오른쪽 hp - 30을 먼저 계산(100 - 30 = 70)하고, 그 결과를 왼쪽 hp에 다시 저장해요. 그래서 hp가 100에서 70으로 바뀌어요. 계산 기호: 더하기 +, 빼기 -, 곱하기 *(×가 아니에요), 나누기 /.
⑦함수 이름print는 "화면에 보여 줘"라는 기능(함수)이에요. 소문자로 써요. Print는 NameError예요.
⑧괄호 ( )함수에 넘길 값을 괄호 안에 넣어요. 함수 이름 바로 뒤에 붙여 쓰고, 여는 괄호와 닫는 괄호가 짝이어야 해요.
⑨쉼표 ,여러 값을 나열할 때 써요. print는 쉼표로 나눈 값 사이에 띄어쓰기 한 칸을 넣어 출력해요.

4-2. 실습: 조건

🎮 게임 개발자는 조건을 이렇게 써요
체력에 따라 게임 오버, 경고, 계속 진행 중 하나를 고르는 규칙을 if로 만들어요.

실습 아래 코드를 새 코드 셀에 붙여 넣고 실행해요.

코드 · 복사해서 Colab 코드 셀에 붙여 넣으세요
hp = 15                  # 지금 체력
if hp <= 0:              # 체력이 0 이하이면
    print("게임 오버")
elif hp < 20:            # 아니고, 20보다 적으면
    print("체력이 부족해요! 포션을 마시세요")
else:                    # 둘 다 아니면
    print("모험을 계속해요")

번호무엇규칙과 주의
①if"만약 ~라면". 소문자로 쓰고, 뒤에 한 칸 띄운 다음 조건을 써요.
②<= (비교)"작거나 같은가?"를 묻는 비교예요. 그 밖의 비교: < 작다, > 크다, >= 크거나 같다, == 같다, != 다르다. 같은지 물을 때는 등호 두 개(==)예요. 등호 하나(=)는 저장이라 뜻이 달라요.
③콜론 :조건 줄 끝에 반드시 붙여요. 빠지면 SyntaxError: expected ':'가 나요.
④들여쓰기콜론 다음 줄은 4칸 들여써요. 들여쓴 줄이 "조건이 맞을 때 할 일"이에요. 안 맞으면 IndentationError. Colab은 콜론 뒤 Enter를 치면 자동으로 들여써 줘요.
⑤elif"아니면, 만약 ~라면"(else if의 줄임). 위 조건이 틀렸을 때만 확인해요.
⑥else:"둘 다 아니라면". 뒤에 조건을 쓰지 않고 바로 콜론을 붙여요.

방금 무슨 일이 일어났나
값에 따라 다른 문장이 출력돼요. 이렇게 상황에 따라 다른 행동을 하게 만드는 것을 조건문이라고 해요. 위에서부터 차례로 확인하다가 처음 맞는 조건 하나만 실행해요. hp 15는 0 이하가 아니고 20보다 적으니 두 번째 문장이 나왔어요.
