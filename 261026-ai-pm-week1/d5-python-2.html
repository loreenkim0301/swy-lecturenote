데이터 분석 맛보기 ① 왜 파이썬인가

데이터 분석 현장에서는 파이썬이 사실상 표준 도구로 쓰여요. 먼저 그 이유를 이해하고, 같은 기초 문법이 데이터 분석에서 어떻게 쓰이는지 직접 실행해요.

1-1. 왜 데이터 분석에는 파이썬을 쓰는가

HTML과 CSS는 화면의 구조와 모양을 정하는 언어여서 계산을 하거나 데이터를 처리할 수 없어요. 자바스크립트는 계산을 할 수 있지만, 주로 브라우저 안에서 화면을 움직이기 위해 발전해 온 언어라서 대용량 데이터를 다루는 도구가 상대적으로 부족해요. 파이썬은 오랜 기간 연구자와 분석가들이 데이터를 다루는 도구를 만들고 공유해 온 덕분에, 표 데이터 처리, 통계, 차트, 머신러닝에 필요한 도구가 가장 풍부하게 갖춰져 있어요.

HTML / CSS자바스크립트파이썬
본래 목적화면 구조와 디자인브라우저 화면의 동작범용 프로그래밍, 데이터 처리
계산·데이터 처리불가능가능하지만 분석 도구가 적음가능, 분석 도구가 가장 풍부
대표 분석 도구없음일부 차트 도구pandas(표), matplotlib(차트), scikit-learn(머신러닝)
실행 위치브라우저주로 브라우저내 컴퓨터, 서버, Colab

오늘 배운 파이썬으로 왜 웹사이트를 바로 만들 수는 없는지, 그리고 웹·앱·크롬 확장 프로그램을 만들려면 어떤 언어가 필요한지 프로그래밍 언어의 세계를 한눈에 정리해요. 이 세션이 다음 세션 "웹의 동작 원리"로 가는 다리예요.

5-1. 파이썬으로 웹사이트를 바로 만들 수 없는 이유

우리가 웹사이트를 볼 때 쓰는 브라우저는 HTML, CSS, 자바스크립트만 알아들어요. 파이썬 코드를 브라우저에 그대로 주면 실행되지 않아요. 파이썬은 브라우저가 아니라 서버나 내 컴퓨터에서 실행되는 언어이기 때문이에요. 파이썬으로 웹 서비스를 만들려면 웹 프레임워크(Flask, Django, Streamlit 등)로 서버를 만들고, 그 서버가 HTML을 만들어 브라우저에 보내도록 해야 하며, 그 서버를 인터넷에 올리는 배포 작업도 따로 필요해요.

HTML / CSS / 자바스크립트파이썬
어디서 실행되나사용자의 브라우저내 컴퓨터, Colab, 서버
역할화면계산, 데이터 처리, 자동화, 서버 로직
비유
HTML은 매장의 진열대, 파이썬은 주방이에요. 손님(브라우저)은 진열대만 보고, 주방은 뒤에서 음식을 만들어 내보내요. 오늘 배운 변수·조건·반복·리스트·random은 자바스크립트에도 똑같이 있어서, 화면 프로토타입을 AI에게 요청할 때도 같은 단어로 말하면 돼요.

5-2. 프로그래밍 언어의 세계: 무엇을 만들려면 어떤 언어가 필요한가

파이썬으로 웹사이트를 바로 만들 수 없다는 것을 알고 나면 자연스럽게 다음 질문이 생겨요. 그러면 웹을 만들려면, 앱을 만들려면, 크롬 확장 프로그램을 만들려면 어떤 언어가 필요할까요? 프로그래밍 언어는 수백 가지가 있지만, PM이 알아야 할 기준은 하나예요. "이 프로그램은 어디에서 실행되는가?" 브라우저에서 돌아가는지, 아이폰에서 돌아가는지, 서버에서 돌아가는지에 따라 쓸 수 있는 언어가 거의 정해져요. 언어를 고르는 것이 아니라, 실행되는 장소가 언어를 정한다고 이해하면 돼요.

또 하나 기억할 점은, 실제 서비스는 대부분 여러 언어를 함께 쓴다는 거예요. 사용자가 보는 화면(프론트엔드), 화면 뒤에서 데이터를 처리하는 서버(백엔드), 데이터를 저장하는 데이터베이스가 각각 다른 언어로 만들어지는 경우가 많아요. 식당으로 치면 홀, 주방, 창고가 각자 다른 도구를 쓰는 것과 같아요. 이 그림은 세션 6에서 다시 봐요.

6-3. 식당 주문으로 보는 웹: 프론트엔드·백엔드·API

브라우저와 서버의 대화는 늘 요청(Request)과 응답(Response) 한 쌍으로 이루어져요. [그림 5-2]의 식당 비유를 이어 가면 프론트엔드, 백엔드, API가 한 번에 정리돼요.
