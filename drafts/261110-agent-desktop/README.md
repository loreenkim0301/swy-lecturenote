## 확인된 것과 확인되지 않은 것

| 구분 | 내용 |
| --- | --- |
| 공식으로 확인 | 설치 명령, 지원 OS, 스냅샷·ref·STALE_REF, 스킬 추가 명령, 개인 정보 주의(agent-desktop README) / 컴퓨터 유즈는 스크린샷 기반, Pro·Max 리서치 프리뷰, 브라우저는 보기만 가능(Claude Code 문서) |
| 언론 보도로만 확인 | 공개 일자(10/28 1.0.0, 10/30 1.0.2, 10/31 보도), Chris Tate의 소개 문구 |
| 확인되지 않음 | 사진 방식보다 빠르고 싸다는 점(일반 추정, 교안에 '추정'으로 표시) / 맥 메모 앱에서 실습이 되는지 |

## 대화 원안에서 바꾼 것

- 비교 표 '설치·쓰는 곳': 컴퓨터 유즈는 데스크톱 앱뿐 아니라 클로드 코드 CLI(macOS)에서도 켤 수 있어 함께 적음(Claude Code 공식 문서)
- 비교 표 '비용': "Claude 요금제 안에서(세부 한도 확인 필요)" → "Pro·Max 요금제 리서치 프리뷰(Team·Enterprise 제외)"로 공식 문서 기준 수정
- 설치: 홈브루 미지원(1.0.2 시점 해설) → 현재 README 기준 `brew install agent-desktop` 가능으로 수정
