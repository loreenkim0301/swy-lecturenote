## 1. 상태 1 — Claude 채팅 기능만 사용

**원리:** Anthropic 서버가 페이지를 받아 오고, AI가 읽어서 정리해 준다. 다음 페이지는 Claude가 주소를 보고 한 번 더 읽는다.

**실습 프롬프트 ① Travel (한 페이지)**

```
아래 주소의 책 목록을 읽고 표로 정리해 CSV 파일로 만들어 줘.
주소: https://books.toscrape.com/catalogue/category/books/travel_2/index.html
열: 제목(잘리지 않은 전체 제목), 가격, 재고
페이지에 있는 책만 넣고, 값을 짐작해서 채우지 마. 확인할 수 없는 칸은 [확인 필요]로 남겨 줘.
파일 첫 줄에 '페이지를 읽었는지(예/아니요), 모은 책 ○권'을 써 줘.
```

**실습 프롬프트 ② Mystery (여러 페이지)**

```
아래 주소의 책 목록을 CSV로 정리해 줘.
주소: https://books.toscrape.com/catalogue/category/books/mystery_3/index.html
열: 제목(잘리지 않은 전체 제목, 링크의 title 속성), 가격, 재고
"next" 링크가 있으면 다음 페이지도 계속 읽고, 없으면 멈춰.
확인할 수 없는 칸은 [확인 필요]로 남기고, 값을 짐작하지 마.
파일 첫 줄에 '페이지를 읽었는지(예/아니요), 모은 책 ○권'을 써 줘.
```

**코드:** 없음 (Claude가 WebFetch 도구를 페이지마다 호출)

**주의**
- 결과를 AI가 정리해서 주므로, 대량·정밀 수집의 기준값으로 쓰지 않는다. 코드로 꺼낸 값(상태 2·3)으로 검증한다.
- 2차 실행 때 2페이지 주소를 읽으려 하자 "이 주소를 읽어도 되는지" 승인 요청이 떴고, 응답이 없어 한 번 취소됐다. 내가 채팅에 직접 적지 않은 주소는 승인을 받아야 할 수 있다. → 다음 페이지 주소까지 프롬프트에 적어 두면 막히지 않는다.

## 2. 상태 2 — 채팅 + Claude in Chrome 확장 프로그램

**원리:** 내 크롬에서 페이지를 연 뒤, 페이지 안에서 자바스크립트를 실행한다. 코드가 HTML 태그에서 값을 그대로 꺼낸다(AI 해석 없음).

**실습 프롬프트 (①·② 한 번에)**

```
Claude in Chrome으로 새 탭을 열고 아래 두 카테고리의 책을 모아 줘.
- https://books.toscrape.com/catalogue/category/books/travel_2/index.html
- https://books.toscrape.com/catalogue/category/books/mystery_3/index.html
페이지 안에서 자바스크립트로 "next" 링크를 따라가며 모든 페이지를 읽어.
제목은 링크의 title 속성, 가격은 p.price_color, 재고는 p.instock.availability에서 가져와.
카테고리별 CSV로 만들고, 사이트에 표시된 전체 권수와 맞는지 확인해 줘. 다 쓴 탭은 닫아 줘.
```

**코드:** `code/스크래핑연습_브라우저수집_다중페이지_v1_20261110.js` (한 카테고리용, 브라우저 콘솔에서도 실행 가능)

**실습 중 생긴 시행착오 (교안 포인트)**
1. 코드를 `(async () => { ... })()`로 감싸면 도구가 결과를 기다리지 않아 빈 값 `{}`이 돌아왔다 → 감싸지 않고 맨 위에서 await 사용.
2. 결과가 길면 잘렸다 → 결과를 페이지 안에 저장해 두고(`window.__all`) 15줄씩 나눠 받았다.
3. 2차 실행 때 결과가 `[BLOCKED: Cookie/query string data]`로 막혔다. 제목의 `&`(Parks & Treasured Sites)와 `PAGES=1` 같은 `=` 기호를 개인정보가 담긴 주소 조각으로 오해한 보호 기능이었다 → 출력할 때만 `&`→`[AMP]`, `=`→`:`로 바꾸고, 저장할 때 원래대로 되돌렸다.

## 3. 상태 3 — Claude 데스크톱 앱 설치

### 3-A. 내장 브라우저로 수집

**원리:** 데스크톱 앱 안의 별도 브라우저 창에서 상태 2와 같은 자바스크립트를 실행한다. 내 크롬과 로그인 상태가 분리되어 있다.

**실습 프롬프트**

```
Claude 데스크톱 앱의 내장 브라우저로 아래 두 카테고리의 책을 모아 줘. (Claude in Chrome은 쓰지 마)
- https://books.toscrape.com/catalogue/category/books/travel_2/index.html
- https://books.toscrape.com/catalogue/category/books/mystery_3/index.html
페이지 안에서 자바스크립트로 "next" 링크를 따라가며 제목·가격·재고를 모아 카테고리별 CSV로 만들어 줘.
```

**코드:** 상태 2와 동일 · **결과:** 성공, 두 실습 모두 상태 2와 완전히 동일. 이번에는 결과가 잘리거나 막히지 않고 한 번에 돌아왔다.

### 3-B. 컴퓨터 유즈로 터미널 앱에 명령 입력

**실습 프롬프트 (시도용)**

```
컴퓨터 유즈로 맥의 터미널 앱을 열고 파이썬 스크립트를 실행해 줘.
```

**확인 결과: 불가 (1차·2차 동일)**
- 터미널·코드 편집기는 컴퓨터 유즈에서 'click' 등급으로만 허용된다. 보기와 왼쪽 클릭만 되고, 글자 입력·키·붙여넣기가 막혀 있다.
- 화면 조작으로 명령을 치는 길은 안전장치로 막혀 있으니, 명령 실행은 3-C(Claude Code 탭)로 한다.

### 3-C. 데스크톱 앱의 <Claude Code> 탭으로 파이썬 실행

**원리:** Claude Code는 내 컴퓨터의 폴더에서 명령을 직접 실행할 수 있다. 그래서 컴퓨터 유즈로는 막혔던 "파이썬 실행"을 여기서 한다. 파이썬 코드는 AI 해석 없이 HTML에서 값을 꺼내므로, 결과는 상태 2·3-A와 같아야 정상이다.

**실습 프롬프트 (Claude Code 탭에 그대로 입력)**

```
이 저장소의 drafts/261110-web-scraping-compare 폴더에서 아래를 순서대로 해 줘.
1. requests, beautifulsoup4가 없으면 설치해 줘.
2. python3 code/스크래핑연습_파이썬수집_v2_20261110.py 를 실행해 줘.
3. python3 code/스크래핑연습_결과대조_v2_20261110.py 를 실행해서 파이썬 결과가 다른 환경 결과와 같은지 알려 줘.
4. README 0번 표의 3-C 행을 실제 결과로 고치고, PR #158 브랜치에 커밋·푸시해 줘.
```

**코드:** `code/스크래핑연습_파이썬수집_v2_20261110.py`
- Travel·Mystery를 한 번에 수집해 `data/스크래핑연습_{travel|mystery}_books_파이썬_v2_20261110.csv`로 저장한다.
- 대조 스크립트가 이 파일을 자동으로 찾아 함께 비교한다.
- 확인된 것: 가짜 HTML로 페이지 이동·전체 제목·`&`·쉼표 제목·CSV 저장까지 정상 동작. **확인 안 된 것:** 실제 사이트 접속(Claude 클라우드 작업 공간은 외부 사이트 접속이 막혀 있어 실행 불가).

## 4. 교안에 넣을 메시지

1. 같은 결과를 얻는 길이 여러 개다. 무엇이 설치되어 있는지(채팅만 / 크롬 확장 / 데스크톱 앱)가 선택지를 정한다.
2. AI가 읽은 값(상태 1)은 코드가 꺼낸 값(상태 2·3)으로 검증한다. 이번에는 같았지만, 같다는 보장은 검증해야 생긴다.
3. 같은 실습을 다시 돌려 같은 결과가 나오는지(재현성)도 확인한다. 이번에는 1차·2차가 같았다.
4. 화면 조작(컴퓨터 유즈)은 만능이 아니다. 터미널처럼 위험한 앱은 안전 등급으로 막혀 있고, 명령 실행은 Claude Code 탭이 맡는다.
5. 보호 기능 때문에 결과가 막히는 일(승인 요청, `[BLOCKED]`)도 실습의 일부다. 막힌 이유를 읽고 방법을 바꾸면 된다.
