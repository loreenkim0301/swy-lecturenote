# 예비 교안(drafts)

수업 일정·대상이 정해지기 전에 미리 준비해 둔 교안을 모아요.

- 폴더 이름: 날짜 없이 주제만 써요. 예: `data-hypothesis-by-user-scale`
- 페이지는 검색에 걸리지 않게 `noindex`로 두고, 저장소 첫 페이지 목록에는 올리지 않아요.
- 수업이 정해지면 `날짜-주제` 폴더(예: `261201-data-hypothesis`)로 옮기고, 교육 개요·타임테이블을 고객사 커리큘럼에 맞춰 고친 뒤 첫 페이지에 링크를 추가해요.
