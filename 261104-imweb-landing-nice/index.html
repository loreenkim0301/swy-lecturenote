아임웹은 랜딩으로,
결제는 나이스 체크아웃으로

강의 판매 페이지를 아임웹으로 만들되, 결제는 아임웹 주문서가 아니라 나이스 체크아웃 상품 페이지로 바로 보내는 방법을 따라 해요. 상세페이지와 주요 버튼은 화면 편집 대신 코드(HTML·CSS)로 고쳐요.

대상코딩 경험 없는 기획자·PM, 강의·디지털 상품을 직접 파는 1인 사업자
도구아임웹, 나이스 체크아웃(판매자 계정), Claude 또는 ChatGPT
결과물상세페이지 1개 + [구매하기]를 누르면 나이스 결제 화면으로 가는 상품
OVERVIEW

교육 개요

교육 목표아임웹을 "보여 주는 가게(랜딩)"로만 쓰고, 결제는 나이스 체크아웃으로 보내는 구조를 이해하고 직접 연결해요.
진행 방식세션 1은 구조 이해, 세션 2~5는 실제 관리자 화면을 보며 따라 하기예요.
주요 내용① 역할 나누기(아임웹·나이스·내 홈페이지) ② 상품 등록과 상세페이지 HTML ③ [Header Code]로 버튼 디자인 바꾸기 ④ [Footer Code]로 [구매하기]를 나이스에 연결 ⑤ 로그인·구매평 끄기 등 랜딩 정리
수업이 끝나면① 아임웹 기본 결제 대신 외부 결제 링크로 보내는 이유를 말한다 ② 상세페이지를 HTML로 넣고 CSS로 꾸민다 ③ 상품마다 다른 결제 주소로 연결한다
이 교안의 화면은 2026년 11월 4일 기준이에요
아임웹과 나이스 체크아웃은 화면이 자주 바뀌어요. 버튼 이름이 다르면 비슷한 이름을 찾아요. 예시는 실제로 운영 중인 치토스 부트캠프 사이트예요.
PREPARE

수업 전 준비

  • 아임웹 계정과 사이트 1개: 기본 주소(예: ○○○.imweb.me)로 충분해요.
  • 나이스 체크아웃 판매자 계정: 로그인은 수업 전에 본인이 직접 해 두세요. 비밀번호와 인증번호는 다른 사람(AI 포함)에게 맡기지 않아요.
  • 판매할 상품 정보: 상품명, 가격, 기간, 대표 이미지(정사각형 권장), 상세페이지에 쓸 내용
  • Claude 또는 ChatGPT: 상세 HTML과 CSS를 만드는 데 써요.
SESSION 1

구조 먼저: 누가 무엇을 맡나요

쇼핑몰 빌더 하나에 모든 걸 맡기지 않고, 역할을 셋으로 나눠요.

1-1. 역할 나누기

LANDING

아임웹

강의를 소개하는 가게 진열대예요. 상세페이지, 커리큘럼 신청(이메일) 폼만 둬요.

PAYMENT

나이스 체크아웃

계산대예요. 반 선택과 결제는 모두 여기서 해요.

DATA

내 홈페이지

장부예요. 수강생 정보와 운영 데이터는 회사 홈페이지(예: 셀렉트웨이 홈)에서 관리해요.

1방문아임웹 상세페이지
2읽기커리큘럼·가격 확인
3[구매하기]아임웹 주문서 건너뜀
4나이스 상품 페이지반 선택·결제
5안내 메일개강 정보 발송

1-2. 왜 아임웹 결제 대신 나이스 체크아웃인가요

아임웹에도 기본 결제(주문서와 PG 결제)가 있어요. 그런데 이번 캠프는 일부러 쓰지 않았어요.

  • 결제를 한 곳에 모아요. 아임웹 밖에서 파는 다른 상품(예: PRD 양식 가이드)도 나이스 체크아웃에서 팔아요. 결제와 정산을 한 화면에서 봐요.
  • 단계를 줄여요. 아임웹 주문서(배송지·추가 정보 입력)를 건너뛰고 바로 결제 화면으로 가요.
  • 아임웹은 바꾸기 쉬운 진열대로 남겨요. 결제와 데이터가 따로 있으니, 나중에 랜딩을 다른 도구로 바꿔도 결제는 그대로예요.
대신 이런 점을 알고 시작해요
결제가 아임웹 밖에서 일어나서 아임웹 [주문] 목록에는 주문이 쌓이지 않아요. 결제 내역은 나이스 체크아웃 관리자에서 봐요. 아임웹 주문서의 "주문 추가 정보"도 쓰이지 않아요.
SESSION 2

아임웹 시작과 상품 등록

사이트를 만들고, 판매할 강의를 상품으로 등록해요.

2-1. 가입하고 사이트 만들기

STEP 1. 아임웹 가입

imweb.me 첫 화면에서 [지금 무료로 시작하기]를 눌러 가입하고 사이트를 하나 만들어요. 처음에는 ○○○.imweb.me 같은 기본 주소가 생겨요.

STEP 2. 관리자 화면 찾기

사이트 주소 뒤에 /admin 을 붙이면 관리자 화면이에요. 예: ○○○.imweb.me/admin. 나중에 로그인 버튼을 숨기면 이 주소로만 들어가니 즐겨찾기 해 두세요.

2-2. 상품 등록

STEP 1. 상품 정보 채우기

[쇼핑] → [상품] → [상품 등록]에서 아래 칸을 채워요.

칸무엇을 쓰나요치토스 예시
이미지목록과 상세 맨 위에 나오는 대표 사진치즈냥 캐릭터(정사각형)
상품명검색·결제 화면에도 보이는 이름[치토스캠프] AI PM 입문 과정 : 만들 줄 아는 기획자
요약 설명가격 아래 짧은 소개. 검색 결과·광고에도 쓰여요기간·시간·운영 횟수를 한 문단으로
가격보여 주는 가격. 실제 결제 금액은 나이스 상품에서 정해요500,000원
가격은 아임웹과 나이스 두 곳에 적어요. 바꿀 때는 두 곳을 같이 바꿔요. 다르면 손님이 헷갈려요.

2-3. 상세페이지를 HTML로 넣기

상세설명 편집기에 글을 하나하나 꾸미면 모바일에서 줄이 엉키기 쉬워요. 그래서 AI로 HTML을 만들어 통째로 붙여 넣어요.

STEP 1. AI로 상세 HTML 만들기

프롬프트
요청: 아임웹 상품 상세설명에 붙여 넣을 HTML을 만들어 줘.
내용: [강의 이름], [대상], [기간·시간], [가격], [커리큘럼 4주 요약], [강사 소개], [자주 묻는 질문]. 위에 없는 숫자·후기·약속(취업 보장 등)은 추가하지 마. 모르는 칸은 [확인 필요]로 남겨.
형식: 전체를 <div class="ctd"> 하나로 감싸고, 섹션마다 <section>과 <h2>를 써. <style>과 <script>는 넣지 마(아임웹 에디터가 지워요). 버튼은 <a class="btnlink">로 만들어.

STEP 2. 코드 보기로 붙여 넣기

상세설명 편집기 오른쪽 위 [</>](코드 보기)를 누르면 HTML이 보여요. 여기에 AI가 만든 HTML을 붙여 넣고 다시 [</>]를 눌러 화면을 확인한 뒤 [저장]해요.

편집기가 바꾸거나 지우는 것
· <style>과 <script>는 저장할 때 지워져요. 그래서 디자인(CSS)은 세션 3의 [Header Code]에 넣어요.
· <b>는 <strong>으로 바뀌어요. CSS도 strong 기준으로 써요.
· class와 style 속성은 남아요.

STEP 3. 결과 확인

SESSION 3

주요 버튼 디자인을 코드로 바꾸기

아임웹 기본 버튼은 모양을 바꿀 수 있는 범위가 좁아요. 사이트 전체에 들어가는 [Header Code]에 CSS를 넣어 원하는 모양으로 바꿔요.

3-1. Header Code와 Footer Code

관리자 왼쪽 메뉴 [설정] → [SEO]로 들어가 아래로 내리면 코드 칸이 있어요.

칸들어가는 곳이 교안에서 넣는 것
Header Code모든 페이지의 <head> 안디자인(CSS): 상세페이지, 버튼, 숨김 처리
Footer Code모든 페이지의 맨 아래동작(JavaScript): [구매하기] → 나이스 연결
코드를 고친 뒤에는 오른쪽 위 [저장]을 꼭 눌러요. 그리고 실제 페이지를 새로 고쳐 확인해요.

3-2. 상세페이지 디자인과 안의 버튼

STEP 1. 상세 CSS 만들기

프롬프트
요청: 위 상세 HTML에 맞는 CSS를 만들어 줘. 아임웹 [Header Code]에 넣을 거야.
내용: 모든 선택자는 .ctd 로 시작해. 글자 색 #141414, 강조 주황 #F7821B, 본문 폭 최대 680px, 모바일(600px 이하)에서 한 줄로 내려오게. <b>는 아임웹이 <strong>으로 바꾸니까 strong 기준으로 써.
형식: <style> … </style> 한 덩어리로만 줘.

STEP 2. 버튼 모양 정하기

상세 HTML 안의 링크 버튼은 모두 class="btnlink"로 만들고, 모양은 CSS 한 곳에서 정해요. 그러면 버튼이 열 개여도 한 번에 바뀌어요.

Header Code · 상세 안의 버튼
<style>
/* 상세페이지 안의 버튼 (상세 HTML에서 <a class="btnlink"> 로 씀) */
.ctd .btnlink{
  display:inline-flex; align-items:center; justify-content:center;
  min-height:48px; padding:0 18px; border-radius:10px;
  background:#F7821B; color:#141414 !important;
  font-weight:800; text-decoration:none;
}
.ctd .btnlink:hover{ filter:brightness(.95); }
</style>

3-3. 입력폼 제출 버튼

"커리큘럼 받기"처럼 이메일을 받는 폼은 디자인 모드의 [입력폼] 위젯으로 만들어요. 기본 버튼은 글자가 위로 붙고, 입력한 글자가 흰색이라 안 보일 수 있어요.

STEP 1. 위젯 ID 복사

디자인 모드에서 위젯을 오른쪽 클릭하면 [위젯ID 복사]가 있어요. 이 ID를 CSS에 써서 그 위젯만 바꿔요.

STEP 2. 버튼과 입력칸 CSS

Header Code · 입력폼
<style>
/* 입력폼 위젯 — [위젯ID 복사]로 얻은 ID를 #w... 자리에 넣어요 */
#w[입력폼위젯ID] ._input_form_submit{
  display:flex !important; align-items:center; justify-content:center;  /* 글자를 버튼 가운데로 */
  width:100%; max-width:360px; height:52px; margin:8px auto 0;
  background:#F7821B !important; border-color:#F7821B !important;
  color:#141414 !important; font-weight:800 !important; font-size:16px !important;
  border-radius:10px !important;
}
/* 입력한 글자가 흰색이라 안 보이던 문제 + 다크모드 대비 */
#w[입력폼위젯ID]{ color-scheme:light; background:#fff !important; }
#w[입력폼위젯ID] input.form-control{
  color:#141414 !important; -webkit-text-fill-color:#141414 !important;
  background:#fff !important; font-size:16px !important;   /* 16px 미만이면 아이폰에서 화면이 확대돼요 */
}
@media (max-width:720px){ #w[입력폼위젯ID] ._input_form_submit{ max-width:none; } }
</style>

STEP 3. 받은 이메일 확인

제출된 이메일은 관리자 [콘텐츠] → [입력폼]에 쌓여요. 오른쪽 위 [내보내기]로 엑셀로 받을 수 있어요.

3-4. 첫 화면은 코드 위젯으로

첫 화면처럼 자유롭게 배치하고 싶은 곳은 디자인 모드의 [코드] 위젯에 HTML과 CSS를 통째로 넣어요.

STEP 1. 코드 설정 열기

코드 위젯을 오른쪽 클릭 → [코드 설정]을 누르면 코드 편집 창이 열려요. 수정 후 [저장] → 오른쪽 위 [게시하기]까지 눌러야 실제 사이트에 반영돼요.

편집 창 오른쪽 안내처럼, Free 버전에서는 코드 위젯의 스크립트가 지워지고 저장돼요. 코드 위젯에는 HTML·CSS만 넣고, 동작이 필요하면 세션 4처럼 [Footer Code]를 써요.
SESSION 4

[구매하기]를 나이스 체크아웃에 연결하기

아임웹 상품의 [구매하기]를 누르면 주문서 대신 나이스 체크아웃 상품 페이지가 바로 열리게 해요.

4-1. 나이스 체크아웃에 상품 만들기

STEP 1. 상품 등록

나이스 체크아웃 관리자(office.nicepay-checkout.co.kr)에 로그인해서 상품을 만들어요. 반이 여러 개면 옵션으로 나누거나 반마다 상품을 따로 만들어요.

STEP 2. 상품 주소 복사

만든 상품의 스토어 페이지를 열고 주소를 복사해요. 모양은 store.nicepay-checkout.co.kr/[스토어주소]/products/[상품번호] 예요.

아임웹 상품명·가격·기간과 나이스 상품 내용이 같은지 꼭 맞춰 봐요. 손님은 두 화면을 이어서 봐요.

4-2. 아임웹 상품 번호 확인

아임웹 상품 페이지 주소 끝의 idx= 뒤 숫자가 상품 번호예요. 예: …/shop_view?idx=4 → 4번.

4-3. Footer Code에 연결 코드 넣기

STEP 1. 코드 붙여 넣기

[설정] → [SEO] → [Footer Code] 맨 아래에 붙이고, NICE 칸에 "아임웹 상품 번호: 나이스 상품 주소"를 적어요.

Footer Code · 구매하기 → 나이스 체크아웃
<!-- 구매하기 → 나이스 체크아웃 상품 페이지로 바로 이동 (아임웹 주문서 생략) -->
<style>a[href="/shop_cart"],._btn_cart,.cart_btn_child,._cart_btn_child{display:none!important}</style>
<script>
(function(){
  /* 아임웹 상품 번호(idx) → 나이스 체크아웃 상품 주소. 상품이 늘면 여기에 한 줄 추가 */
  var NICE = {
    4: 'https://store.nicepay-checkout.co.kr/[스토어주소]/products/[상품번호]',
    5: 'https://store.nicepay-checkout.co.kr/[스토어주소]/products/[상품번호]'
  };
  function idx(){ var m = location.search.match(/[?&]idx=(\d+)/); return m ? m[1] : null; }

  /* 연결된 상품이면 아임웹 옵션(반 선택) 칸을 숨김 — 반은 나이스 결제 화면에서 골라요 */
  if (NICE[idx()]) {
    var hs = document.createElement('style');
    hs.textContent = '.opt-group{display:none!important}';
    document.head.appendChild(hs);
  }

  /* PC·모바일 [구매하기]를 누르면 나이스 상품 페이지로 이동 */
  document.addEventListener('click', function(e){
    var b = e.target.closest && e.target.closest('._btn_buy, a.buy, a[onclick*="showMobileOptions"]');
    if (!b) return;
    var u = NICE[idx()];
    if (!u) return;                 /* 연결 안 된 상품은 원래대로 */
    e.preventDefault(); e.stopPropagation(); e.stopImmediatePropagation();
    location.href = u;
  }, true);
})();
</script>

STEP 2. 코드가 하는 일

  • [구매하기]를 가로채요. PC 버튼(_btn_buy)과 모바일 첫 버튼(옵션 창을 여는 버튼)을 모두 잡아요. 옵션을 고르지 않아도 바로 나이스로 가요.
  • 연결한 상품만 바꿔요. NICE 목록에 없는 상품은 원래대로 아임웹 주문서로 가요.
  • 헷갈리는 칸을 숨겨요. 장바구니 버튼과 아임웹 옵션(반 선택) 칸을 숨겨요. 반은 나이스에서 골라요.

STEP 3. 확인

  • PC: 반을 고르지 않고 [구매하기] → 나이스 상품 페이지가 열리는지
  • 모바일: 아래 [구매하기] → 옵션 창 없이 바로 나이스로 가는지
  • 다른 상품: 연결하지 않은 상품은 원래 주문서가 열리는지

랜딩 전용으로 정리하기

결제와 회원 관리를 아임웹에서 하지 않으니, 손님이 헷갈릴 버튼을 끄고 숨겨요.

5-1. 로그인·회원가입 끄기

[고객] → 고객 목록 왼쪽 안내의 [가입 및 그룹설정]에서 "로그인/가입 사용" 체크를 풀고 [저장]해요. 사이트에 로그인·회원가입 버튼이 나오지 않아요.

화면 안내처럼 이미 가입된 계정(관리자)은 정해진 경로로 계속 로그인할 수 있어요. 관리자는 ○○○.imweb.me/admin 으로 들어가요.

5-2. 상단 버튼·구매평 숨기고 Q&A 폭 맞추기

아래 CSS를 [Header Code]에 더해요. 위젯 ID 자리는 3-3처럼 [위젯ID 복사]로 채워요.
