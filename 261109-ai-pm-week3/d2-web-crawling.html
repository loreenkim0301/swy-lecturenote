오늘의 단어

오늘 처음 나오는 말을 먼저 짧게 짚고 시작해요. 수업 중에 다시 나오면 이 표로 돌아와요.

단어뜻
크롤링(crawling)프로그램이 웹 페이지를 열어 필요한 정보를 모으는 일. 페이지에서 필요한 부분만 뽑는 일을 스크래핑이라고도 해요. 수업에서는 둘을 함께 크롤링이라고 불러요.
크롤러크롤링을 하는 프로그램. 로봇(bot)이라고도 불러요.
robots.txt사이트가 크롤러에게 "여기는 들어와도 되고, 여기는 들어오지 마"를 적어 둔 파일
이용약관사이트를 쓰는 사람이 지켜야 할 규칙을 적은 글
요청 간격크롤러가 페이지를 한 번 연 뒤 다음 페이지를 열기까지 쉬는 시간
HTML 태그 · 속성웹 페이지를 이루는 상자(<h3>, <a> 등)와, 상자에 붙은 이름표(class, title 등)
개발자 도구크롬에서 웹 페이지의 HTML을 들여다보는 도구. 1주차 금요일에 열어 봤어요.
라이브러리남이 만들어 둔 코드 묶음. 오늘은 requests(페이지 열기), BeautifulSoup(HTML에서 찾기), pandas(표 만들기)를 써요.
원본 · 정리본처음 모은 그대로의 데이터와, 정리 규칙을 적용한 데이터. 월요일에 배웠어요.
SESSION 1 · 09:20–10:20

모으기 전에 확인할 것

월요일에는 사용자가 직접 넣은 데이터를 모았어요. 오늘은 다른 사람이 만든 웹 페이지에서 모아요. 그래서 모으기 전에 그 사이트가 정한 약속을 확인해요.

왜 하나?크롤링 코드는 몇 줄이면 돼요. 그래서 더 조심해야 해요. 사이트가 막아 둔 곳을 모으거나 너무 자주 요청하면, 사이트에 부담을 주고 사이트가 정한 약속을 어기게 돼요.

개념1-1. 크롤링이란?

크롤링이란?

크롤링은 프로그램이 웹 페이지를 열어 필요한 정보를 모으는 일이에요. 사람이 복사해서 붙여 넣던 일을 코드가 대신해요.

어떤 문제를 해결하나요?

다른 쇼핑몰의 상품 가격이나 책 목록처럼 내 서비스 밖에 있는 정보는 내 시트에 저절로 쌓이지 않아요. 상품이 1,000개라면 손으로 옮기다가 틀리기 쉬워요. 크롤링을 하면 같은 규칙으로 빠르게 모을 수 있어요.

구분월요일 · 사용자의 데이터화요일 · 외부의 데이터
데이터가 있는 곳내 서비스의 입력 화면다른 사람이 만든 웹 페이지
모으는 방법입력 화면 → 구글 시트, GA크롤링(파이썬 코드, 클로드)
먼저 확인할 것개인정보를 어디까지 받을지그 사이트가 모아도 된다고 했는지
정리 방법똑같아요. 원본은 그대로 두고, 규칙으로 정리본을 만들어요.

조심할 점

크롤링하기 전에 아래 네 가지를 확인해요. 하나라도 걸리면 모으지 않거나, 사이트에 먼저 물어봐요.

확인할 것어디서 보나요무엇을 보나요
robots.txt사이트 주소 끝에 /robots.txt를 붙여 열기모으려는 주소가 Disallow(들어오지 마)에 들어 있는지
이용약관사이트 맨 아래쪽의 이용약관 링크자동으로 정보를 모으는 일을 금지하는 문장이 있는지
개인정보모으려는 페이지이름·연락처·이메일·아이디처럼 사람을 알아볼 수 있는 정보가 섞여 있는지. 섞여 있으면 그 칸은 모으지 않아요.
요청 간격내가 짜는 코드한 페이지를 연 뒤 쉬는 시간이 있는지. 수업에서는 1초 이상 쉬어요.

robots.txt는 크롤러에게 하는 부탁이에요. 문을 잠그는 장치가 아니라서, 지키는 것은 크롤링하는 사람의 몫이에요. robots.txt에서 막지 않았다고 아무거나 모아도 된다는 뜻도 아니에요.

출처: Google 검색 센터 robots.txt 소개("robots.txt 파일의 지시는 크롤러의 행동을 강제할 수 없으며, 지키는 것은 크롤러의 몫") · IETF RFC 9309 Robots Exclusion Protocol("이 규칙은 접근 허가의 한 형태가 아니다", User-agent: * 그룹, Disallow) (2026.11.08 확인)

실습1-2. 연습 사이트와 YES24의 robots.txt 읽기

오늘 크롤링할 연습 사이트와, 수요일에 링크로 이어 갈 실제 서점 YES24를 함께 확인해요.

STEP 1. 연습 사이트가 크롤링을 허락했는지 보기

크롬에서 https://toscrape.com/ 을 열어요. 첫 화면에 이 사이트가 무엇인지 적혀 있어요.

예시toscrape.com 첫 화면에 적힌 내용

적힌 내용뜻
Web Scraping Sandbox웹 스크래핑 연습장
a safe place for beginners learning web scraping웹 스크래핑을 배우는 사람을 위한 안전한 곳
Books: 1,000 items, 20 per page, no JavaScript가상의 서점. 책 1,000권, 한 페이지에 20권, 자바스크립트 없이 열려요.

이어서 https://books.toscrape.com/ 을 열어요. 위쪽 경고 문구를 읽어요. "This is a demo website for web scraping purposes."는 웹 스크래핑용 데모 사이트라는 뜻이에요. 가격과 별점은 무작위로 붙인 값이라 실제 의미가 없다고도 적혀 있어요.

STEP 2. 실제 사이트의 robots.txt 열기

크롬 주소창에 https://www.yes24.com/robots.txt 를 넣어 열어요. 글자만 있는 화면이 나와요. 아래 표로 읽는 법을 먼저 봐요.

줄뜻
User-agent: *그 아래 줄은 모든 크롤러에게 하는 말이에요.
User-agent: AhrefsBot그 아래 줄은 이름이 AhrefsBot인 크롤러에게만 하는 말이에요.
Disallow: /member/주소가 /member/로 시작하는 곳에는 들어오지 말라는 뜻이에요.
Disallow: /사이트 전체에 들어오지 말라는 뜻이에요.
규칙이 없는 주소막지 않은 주소예요. 그래도 이용약관과 요청 간격은 따로 지켜요.

STEP 3. YES24 robots.txt에서 찾기

열어 둔 YES24 robots.txt에서 아래 네 가지를 직접 찾아요. 찾은 다음 정답과 비교해요.

  • 모든 크롤러(User-agent: *)에게 사이트 전체를 막았나요?
  • 모든 크롤러에게 막은 경로 세 개를 찾아요.
  • 사이트 전체를 막은 크롤러 이름 두 개를 찾아요.
  • Allow 줄이나 Crawl-delay(요청 간격) 줄이 있나요?
정답 비교
질문YES24 robots.txt (2026.11.08 확인)
모든 크롤러에게 사이트 전체를 막았나요?아니요. User-agent: * 아래에 Disallow: / 줄은 없어요.
모든 크롤러에게 막은 경로회원 경로(/member/), 예전 검색 결과 주소(/searchCenter/searchResult.aspx), 상품 리뷰 목록(/Product/CommunityModules/GoodsReviewList) 등 여러 경로를 막아요.
사이트 전체를 막은 크롤러AhrefsBot, SemrushBot, MJ12bot 등 이름이 적힌 여러 크롤러에게 Disallow: /로 사이트 전체를 막아요.
Allow·Crawl-delay 줄없어요.

막히면

robots.txt가 길어서 내가 모으려는 주소가 막혔는지 알기 어려우면, 클로드에게 물어봐요. robots.txt 화면의 글자를 모두 복사해 붙여 넣어요.

프롬프트

프롬프트 1 · 필요할 때만 클로드에 붙여 넣으세요
요청: 아래 robots.txt를 보고, 내가 모으려는 주소가 모든 크롤러(User-agent: *)에게 막혀 있는지 알려 줘.
내용: 모으려는 주소는 [주소]야. robots.txt 내용은 [붙여 넣기]야. robots.txt에 없는 규칙은 추가하지 마.
형식: '막힘/막히지 않음' 한 줄, 그렇게 판단한 robots.txt의 줄을 그대로 한 줄 인용.

SESSION 2 · 10:30–11:10

웹 페이지에서 모을 곳 찾기

1주차 금요일에 개발자 도구를 처음 열어 봤던 것 기억하시나요? 오늘은 그 도구로 책 제목과 가격이 HTML의 어디에 들어 있는지 찾아요.

왜 하나?크롤링 코드는 "이 이름표가 붙은 상자의 글자를 가져와"처럼 위치로 정보를 찾아요. 책 한 권의 HTML을 클로드에게 보여 주면, 클로드가 그 위치에 맞는 코드를 짜요.

개념2-1. HTML 태그와 속성이란?

HTML 태그와 속성이란?

웹 페이지는 HTML 태그라는 상자로 만들어져요. 예를 들어 <h3>는 제목 상자, <a>는 링크 상자예요. 상자에는 class나 title 같은 이름표(속성)가 붙어 있어요.

어떤 문제를 해결하나요?

화면에서 책 제목은 사람 눈에만 '제목'이에요. 코드는 "어떤 태그, 어떤 이름표"로 알아봐요. 그래서 모을 정보마다 태그와 이름표를 찾아 두면, 1,000권도 같은 규칙으로 모을 수 있어요.

조심할 점

화면에 보이는 글자와 HTML 안의 값이 다를 수 있어요. 긴 책 제목은 화면에서 '...'으로 잘려 보이지만, 전체 제목은 링크의 title 속성에 들어 있어요. 화면 글자만 모으면 잘린 제목이 쌓여요.

③별점은 1~5 숫자로(One → 1 … Five → 5)형식 맞추기

클로드로 크롤링하는 실무 방법

코드를 직접 돌리지 않고, 클로드에게 웹 페이지를 읽게 해서 표로 받는 방법이에요. 같은 사이트의 여행(Travel) 분류 책 목록으로 해 보고, 3·4세션의 파이썬 방법과 견줘요.

왜 하나?실무에서는 페이지 몇 개만 한 번 정리하면 되는 일이 많아요. 그때마다 코드를 짜지 않고 클로드에게 맡기면 빨라요. 대신 결과가 맞는지 확인하는 방법을 함께 알아야 해요.

개념6-1. 클로드의 웹 가져오기와 파일 만들기란?

웹 가져오기란?

클로드의 [웹 검색]이 켜져 있으면, 내가 준 주소의 웹 페이지 내용을 클로드가 직접 가져와 읽을 수 있어요. 클로드 도움말은 이것을 웹 가져오기(web fetch)라고 불러요. 답에는 출처 링크가 함께 붙어요.

파일 만들기란?

클로드는 코드를 실행해 CSV·엑셀 같은 파일을 만들어 줄 수 있어요. 설정에서 [코드 실행 및 파일 생성](새 설정 화면에서는 [파일 생성 및 편집])이 켜져 있어야 해요. 만든 파일은 내려받을 수 있어요.

어떤 문제를 해결하나요?

웹 페이지의 표를 손으로 옮기거나, 한 번 쓰고 말 코드를 짜지 않아도 돼요. "이 주소의 책 목록을 CSV로 만들어 줘."라고 하면, 읽기와 파일 만들기를 한 대화에서 끝낼 수 있어요.

조심할 점

  • 웹 검색과 웹 가져오기는 사용량 한도에 포함돼요. 긴 페이지를 많이 읽으면 한도를 빨리 써요.
  • 어떤 사이트의 링크는 열리지 않을 수 있어요. 클로드가 페이지를 못 읽었는데도 표를 만들었는지 꼭 확인해요.
  • 웹 페이지에 숨겨진 지시문이 클로드를 속일 수 있다고 공식 도움말이 안내해요. 처음 보는 사이트를 읽게 할 때는 클로드가 하는 일을 지켜봐요.
  • robots.txt·이용약관·개인정보·요청 간격 확인은 클로드로 모을 때도 똑같이 해요.
