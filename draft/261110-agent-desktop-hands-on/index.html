1

인스타에서 본 도구, agent-desktop

왜 알아야 하나?AI에게 컴퓨터 일을 맡길 때, 무엇을 어떻게 시키는지 알아야 안전하게 쓸 수 있어요.

설명1-1. 이름과 한 문장 소개

얼마 전 인스타그램에서 이런 게시물을 봤어요. AI가 내 컴퓨터 화면의 버튼을 직접 눌러 주는 무료 도구가 나왔다는 이야기였어요.

이름은 agent-desktop이에요. 웹 서비스 회사 Vercel의 연구팀(Vercel Labs)이 무료로 공개했어요. 오늘은 이 도구가 어떤 건지 알아보고, 계산기 앱으로 같이 써 봐요.

agent-desktop은 AI가 아니에요. 클로드 코드 같은 AI에게 앱 버튼을 누르는 손을 달아 주는 도구예요. 무엇을 누를지는 AI가 정하고, agent-desktop은 정해진 버튼을 실제로 눌러요.

설명1-2. 어떻게 움직이나요

앱 화면에는 눈에 보이는 그림 말고도, 화면 낭독기가 읽는 "이 화면에 있는 버튼 이름표 목록"이 숨어 있어요.

보기 이 이름표 목록을 읽어서 버튼마다 번호표를 붙여요.
누르기 AI가 "7번 눌러"라고 하면 그 버튼을 눌러요.
다시 보기 목록을 다시 읽어서 제대로 눌렸는지 확인해요.

기본 설정에서는 내 마우스 커서를 움직이지 않고 조용히 눌러요.

2

시작하기 전에 약속해요

이 도구를 쓰려면 맥에서 [손쉬운 사용] 권한을 줘야 해요.

주의2-1. 이 권한은 컴퓨터 전체의 열쇠예요

이 권한은 앱 하나에만 주는 것이 아니에요. 권한을 받은 프로그램은 화면에 있는 거의 모든 앱의 버튼을 읽고 누를 수 있어요. 그래서 오늘은 아래 약속을 지켜요.

  • 연습은 계산기처럼 중요한 정보가 없는 앱에서만 해요
  • 은행·메신저·메일 앱은 모두 닫고 시작해요
  • AI가 버튼을 누르기 전에는 나에게 먼저 물어보게 해요
  • 연습이 끝나면 권한을 꼭 다시 꺼요
3

같이 써 볼까요?

계산기에서 7 + 8을 AI의 방식으로 눌러 봐요.

STEP 13-1. 설치하고 권한 상태 보기

터미널을 열고 아래 세 줄을 한 줄씩 실행해요.

터미널
npm install -g agent-desktop
agent-desktop version
agent-desktop permissions

확인할 점버전 숫자가 나오는지 봐요. permissions에서 손쉬운 사용이 허용(granted)이면 준비 끝이에요. 아니라면 [시스템 설정] → [개인정보 보호 및 보안] → [손쉬운 사용]에서 사용 중인 터미널 앱만 켜요.

막히면권한 오류가 나면 앞에 sudo를 바로 붙이지 말고, 오류 문구를 클로드 코드에 붙여 넣어 원인부터 물어봐요.

STEP 23-2. 계산기 버튼 목록 보기

계산기 앱을 열고 버튼 목록을 읽어 봐요. 한국어 맥에서는 앱 이름을 계산기라고 써야 해요.

터미널
agent-desktop snapshot --app 계산기 -i

확인할 점버튼마다 번호표가 붙어 나와요. 7, 더하기, 8, 등호 버튼의 번호표를 찾아 적어 둬요. (예: 7 = e7, 더하기 = e18, 8 = e8, 등호 = e21)

막히면AMBIGUOUS_TARGET 오류가 나면 계산기 창이 여러 개 열려 있어요. 창을 하나만 남기고 다시 해요.

STEP 33-3. 번호로 누르기

7 → 더하기 → 8 → 등호 순서로 눌러요. 번호표 자리에는 3-2에서 받은 스냅샷 이름과 번호를 넣어요.

터미널
agent-desktop click @[스냅샷 이름]:e7
agent-desktop click @[스냅샷 이름]:e18
agent-desktop click @[스냅샷 이름]:e8
agent-desktop click @[스냅샷 이름]:e21

확인할 점번호는 사람마다, 스냅샷마다 달라요. 3-2에서 나온 번호를 그대로 써요. 화면이 바뀌면 예전 번호는 쓸 수 없어요(STALE_REF).

STEP 43-4. 다시 읽어서 확인하기

누른 뒤에는 목록을 다시 읽어요. "눌렀다"는 응답과 "맞게 눌렸다"는 확인은 다른 일이에요.

터미널
agent-desktop snapshot --app 계산기

확인할 점입력창에 7+8, 결과에 15가 보이나요? 마우스 커서가 움직이지 않았는지도 봐요.

STEP 53-5. 클로드 코드에게 확인받고 누르게 시키기

이번에는 직접 입력하지 않고 AI에게 시켜 봐요. 아래 프롬프트를 클로드 코드에 붙여 넣어요.

프롬프트
요청: agent-desktop으로 계산기 앱에서 7 더하기 8을 계산해 줘.
내용: 먼저 `agent-desktop skills get desktop`을 읽고 규칙을 따라 줘. 버튼을 누르기 전에 어떤 버튼을 왜 누르는지 나에게 먼저 말하고, 내가 승인하면 눌러 줘. 계산기 말고 다른 앱은 건드리지 마.
형식: 누를 때마다 쓴 번호(ref)를 한 줄씩 보여 주고, 마지막에 다시 읽어서 결과가 맞는지 확인해 줘.
  • AI가 누르기 전에 나에게 물어봤나요?
  • '보기 → 누르기 → 다시 보기' 순서로 일했나요?
  • 계산기 말고 다른 앱을 건드리지 않았나요?
  • 결과가 15인가요?

막히면AI가 묻지 않고 눌렀다면 바로 멈추고 강사에게 알려요.

4

마무리: 권한 끄기와 돌아보기

연습이 끝났어요. 열쇠를 돌려받을 차례예요.

정리4-1. 손쉬운 사용 권한 끄기

1 화면 왼쪽 위 애플 메뉴 → [시스템 설정]을 열어요.
2 [개인정보 보호 및 보안] → [손쉬운 사용]으로 가요.
3 오늘 쓴 앱(터미널 등)의 스위치를 꺼요.
4 같은 곳의 [화면 및 시스템 오디오 녹음]에도 같은 앱이 있으면 꺼요.

확인할 점터미널에서 agent-desktop permissions를 실행했을 때 손쉬운 사용이 denied로 나오면 꺼진 거예요. 용도를 모르는 다른 앱의 스위치는 건드리지 않아요.

도구까지 지우려면npm uninstall -g agent-desktop

정리4-2. 오늘 가져갈 것

  • agent-desktop version으로 버전이 나왔다
  • 계산기 버튼에 번호표가 붙어 나온 것을 봤다
  • 7+8=15를 번호로 눌러서 만들었다
  • 누른 뒤 다시 읽어서 15를 확인했다
  • AI가 누르기 전에 나에게 물어봤다
  • 연습이 끝나고 권한을 껐다
생각해 볼까요?

AI에게 열쇠를 줄 때는 규칙이 필요해요

① AI가 "눌렀어요"라고 말하는 것과 내가 "제대로 눌렸네"라고 확인하는 것은 왜 다른 일일까요?
② 읽기만 하기 → 물어보고 누르기 → 끝나면 열쇠 돌려받기. 내 업무에서는 어떤 규칙이 필요할까요?
③ 내 일에서 AI가 대신 눌러 주면 좋은 일과 절대 맡기면 안 되는 일은 무엇일까요?
