1

수업 전에 확인할 사실

SNS 소개 글의 내용은 공식 저장소 README와 직접 조회한 값으로 대조했어요.

요약1-1. 한 줄 요약

AI(Claude Code·Codex 등)가 내 컴퓨터의 앱 버튼을 눌러 주게 해 주는 무료 명령어 도구예요. 화면 사진을 보고 추측하는 대신, 운영체제가 가진 "버튼 목록(접근성 트리)"을 읽고 번호로 눌러요.

대조1-2. SNS 소개 글과 공식 자료 대조

SNS 소개 글 주장공식 확인 결과판정
Vercel이 공개한 무료 오픈소스vercel-labs 저장소, Apache-2.0 라이선스맞음
깃허브 별 4,300+2026-11-02 gh 조회 기준 별 약 7,233 · 포크 531시점 차이 (게시 당시 수치는 미확인)
접근성 기능으로 버튼 목록을 읽고 번호로 누름snapshot → ref로 동작 → 재snapshot 구조맞음
기본 설정에서 마우스·키보드를 안 건드림Headless by default, --headed를 줘야 실제 입력. 단 이슈 #432(대상 없는 press는 세션 전체에 키 입력)가 논의 중대체로 맞음, 예외 있음
맥·윈도우·리눅스 지원macOS / Windows / Linux CLI. 윈도우·리눅스는 버그 이슈가 많음맞음 (맥이 가장 안정적)
에이전트마다 이름표 커서cursor-overlay 명령은 확인. '에이전트별 이름표' 세부 동작은 README에서 확인 안 됨미확인
동시에 3개 커서순차 실행. 서로 다른 앱 동시 실행은 열린 PR #436연출 (실제 동작은 순차)
화면 정보에 개인정보가 담길 수 있음README가 snapshot·클립보드·스크린샷에 포함될 수 있다고 명시맞음
SNS 수치(별 개수 등)는 교안에 그대로 쓰지 않아요. 인용할 때는 공식 저장소 기준과 확인 날짜를 함께 적어요.
2

강사 맥 실습 결과

2026-11-02 macOS에서 agent-desktop 1.0.2로 계산기 앱을 눌러 본 기록이에요.

결과2-1. 계산기 7+8 실습

단계한 일결과
설치 전 확인npm 패키지의 저장소·라이선스 확인vercel-labs/agent-desktop, Apache-2.0 일치
설치npm install -g agent-desktop성공, 버전 1.0.2 (macOS, aarch64)
권한 확인agent-desktop permissions손쉬운 사용·화면 기록 허용 상태 (설정은 바꾸지 않음)
보기snapshot --app 계산기 -i버튼 24개에 번호표 (7=e7, 더하기=e18, 8=e8, 등호=e21)
누르기click으로 7 → 더하기 → 8 → 등호4번 모두 전달됨 (delivered_unverified)
다시 보기재 snapshot입력 7+8, 결과 15 확인, 마우스 커서는 움직이지 않음

메모2-2. 실습에서 알게 된 점

  • 한국어 맥에서는 앱 이름이 계산기예요. Calculator로 쓰면 APP_NOT_FOUND 오류가 나요
  • 같은 앱의 창이 여러 개 남아 있으면 AMBIGUOUS_TARGET 오류가 나요. list-windows로 창 ID를 보고 --window-id로 지정해요
  • 클릭은 전달 여부만 알려 주므로(delivered_unverified) 반드시 다시 읽어 확인해요. 같은 클릭을 재전송하면 중복 입력 위험이 있어요(retry: unsafe)
  • get 명령은 인자 형식 오류가 한 번 났고, 결과 확인은 snapshot 재조회로 대체했어요
  • 번호표는 스냅샷이 바뀌면 달라져요. 학생 화면의 번호는 이 교안의 예시와 다를 수 있어요
실행하지 않은 것 학생용 3-5의 클로드 코드 프롬프트(클릭 전에 물어보는지)와 스킬 설치는 아직 돌려 보지 않았어요. 수업 전에 먼저 시험해요.
3

수업 운영 원칙

맥의 손쉬운 사용 권한은 앱별로 줄 수 없어요. 권한을 받은 프로그램은 화면의 거의 모든 앱을 읽고 누를 수 있고, --app 옵션은 편의용 필터일 뿐 보안 경계가 아니에요.

원칙3-1. 어떻게 쓰면 좋을까

원칙이유·방법
권한은 실습할 때만 켜고, 끝나면 바로 끈다켜 둔 시간만큼 위험이 계속돼요. 학생용 4-1의 순서대로 끄게 해요
연습용 계정이나 별도 맥에서 시험한다새 macOS 사용자를 만들어 그 계정에서만 권한을 켜면 평소 계정은 영향이 없어요
클릭 전에 반드시 사람에게 확인받게 한다프롬프트에 "클릭 전에 어떤 버튼을 왜 누르는지 말하고 내 승인을 받아라"를 넣어요
은행·메신저·메일이 열려 있으면 쓰지 않는다화면 목록에 그 내용이 그대로 들어올 수 있어요. 수업 시작 전에 모두 닫게 해요
처음에는 읽기 전용(snapshot, find, get)만 쓴다클릭·입력은 익숙해진 뒤 계산기 같은 무해한 앱에서만 해요
한 번에 앱 하나, 동작 하나동작마다 다시 읽어 확인하고 같은 클릭을 반복 전송하지 않아요
AI가 웹페이지·문서·메일을 읽는 작업과 같이 쓰지 않는다그 안의 숨은 지시(프롬프트 인젝션)에 속아 권한이 있는 앱을 조작할 수 있어요

준비3-2. 수업 환경 준비

  • 비개발자에게는 npm 전역 설치와 권한 설정이 첫 관문이에요. 사전 설치 확인 시간을 따로 잡아요
  • 설치 중 권한 오류가 나면 sudo를 바로 붙이지 않고 오류 문구부터 AI에게 물어보게 해요
  • 권한을 준 앱 목록(손쉬운 사용)은 사람마다 달라요. 용도를 모르는 항목은 건드리지 말라고 먼저 안내해요
  • 계산기 대신 메모·Finder로 바꿀 때는 중요한 파일이 없는 상태에서 해요
4

비판적 검토

수업에 넣기 전에 따져 볼 점이에요.

검토4-1. 도입 전 판단 포인트

  • 권한 범위가 커요. 업무용 메일·결제 앱이 열린 상태에서는 실습하지 않아요
  • 개인정보가 새는 길이 있어요. snapshot 결과(JSON)에 화면 텍스트가 담겨요. AI 대화·로그·깃허브에 그대로 올리지 않아요. README도 직접 경고해요
  • "동시에 3개 커서"는 연출이에요. 실제 동작은 순차라서 생산성 과장 홍보에 쓰지 않아요
  • 대안과 겹쳐요. Claude 자체의 컴퓨터 사용(computer use), Claude in Chrome(웹 전용)과 역할이 겹쳐요. agent-desktop의 강점은 데스크톱 네이티브 앱 + 픽셀 추측 없음 + 터미널에서 Claude Code·Codex 공통 사용이에요
  • 브라우저·오피스 앱은 아직 불안정해요. Arc 스냅샷 실패(#465), 큰 Chrome 탭 크기 오류(#463), Word 본문 미노출(#479). 수업 데모는 계산기·메모·Finder가 안전해요
5

깃허브 논의 동향

2026-11-02 gh로 조회한 vercel-labs/agent-desktop의 PR·이슈 제목과 번호 기준이에요. 본문 전체는 읽지 않았어요.

안전5-1. 엉뚱한 버튼을 누르지 않게

  • #427, #429, #428(닫힘), #441, #442(열림): 화면이 바뀐 뒤에도 번호표가 같은 요소를 가리키는지 확인하는 방식을 여러 번 다시 작성했어요. 댓글이 가장 많아요
  • #445(병합): 팝업 상황에서 번호표를 발행하기 전에 맥락을 검증해요
  • #454: 창이 닫힌 번호표는 STALE_REF로 알려줘요

안전5-2. 내 키보드를 건드리나

  • 이슈 #432: macOS에서 대상 지정 없는 press가 --headed 없이도 세션 전체에 키 입력을 보내요. 문서 PR #476으로 설명을 보강 중이에요
  • 이슈 #424, PR #475: 관찰 실패 시 --headed만 복구 방법으로 안내해 사용자의 키보드를 가져가던 문제예요
  • 이슈 #412, PR #468: ~/.agent-desktop 폴더 권한이 755이면 명령이 실패해요

기능5-3. 새 기능 요청

  • #436: 서로 다른 앱에 대한 동작을 동시에 실행. 아직 열린 PR이에요
  • #438, #477: 화면 좌표의 요소를 누르거나 알아내기
  • #467: 에이전트 커서 표시 시간 조절 · #443: 메뉴 단축키 노출 · #439: JSON을 표준입력으로 받기

현황5-4. 윈도우·리눅스와 맥 불편

  • 리눅스 Wayland(#437, #426, #474)와 윈도우(#440, #456, #457, 이슈 #478, #459, #422)는 버그 이슈가 많은 단계예요. 맥이 가장 안정적이에요
  • 이슈 #398, PR #471: 권한 안내가 npm 심볼릭 링크 경로를 알려줘서 허용해도 적용되지 않는 문제예요. 권한을 줘도 안 되면 실제 실행 파일 경로를 의심해요

체크6-1. 정식 교안으로 옮기기 전에
