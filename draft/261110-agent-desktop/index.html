사진 대신 이름표로

AI가 내 컴퓨터 앱을 누르는 방법은 하나가 아니에요. 화면 사진을 보고 누르는 방법이 있고, 앱이 붙여 둔 버튼 이름표를 읽고 누르는 방법이 있어요. Vercel Labs가 2026년 10월에 공개한 agent-desktop으로 두 번째 방법을 알아봐요.

다루는 것agent-desktop · 접근성 트리 · 클로드 컴퓨터 유즈와 비교
방식개념 → 비교 → 실습 1개
준비물맥(macOS 13 이상) · 클로드 코드 · Node.js(npm)
끝나면사진 방식과 이름표 방식의 차이를 내 말로 설명할 수 있어요

1

agent-desktop이란?

왜 알아야 하나?AI에게 내 컴퓨터 앱 일을 맡길 때, 도구마다 '보는 법'이 달라서 잘하는 일과 못 하는 일이 달라요.

설명1-1. 한 문장으로 말하면

agent-desktop은 Vercel Labs가 만든 무료 오픈소스 명령어 도구(CLI)예요. AI 에이전트가 내 컴퓨터의 데스크톱 앱을 보고 누를 수 있게 해 줘요.

앱 화면을 사진으로 찍지 않아요. 운영체제의 접근성 트리를 읽어서 버튼마다 번호를 붙인 목록(JSON)으로 돌려줘요.

agent-desktop은 AI가 아니에요. 안에 AI 모델이 들어 있지 않아요. 클로드 코드 같은 코딩 에이전트에게 '손'을 달아 주는 도구예요. 생각은 클로드가 하고, agent-desktop은 클로드가 고른 번호를 실제로 눌러요.
항목내용
만든 곳Vercel Labs. 웹 브라우저용 도구 agent-browser를 만든 Chris Tate가 '컴퓨터 전체용 agent-browser'라고 소개했어요
공개2026.10.28 1.0.0 → 2026.10.30 1.0.2 (UTC). 언론 보도는 10월 31일부터 나왔어요
지원 운영체제macOS 13 이상 · Windows 10(1809) 이상 · Ubuntu 24.04 이상
라이선스Apache-2.0. 상업적으로 써도, 고쳐도, 다시 배포해도 사용료가 없어요
다루는 범위데스크톱 앱만. 웹 페이지는 같은 팀의 agent-browser가 맡아요

예시1-2. 두 친구에게 일을 맡겨 봐요

멀리 있는 친구에게 내 컴퓨터로 '저장'을 눌러 달라고 부탁한다고 생각해 봐요.

사진을 받는 친구 · 클로드 컴퓨터 유즈

내 화면 사진을 받아 보고 "오른쪽 위 파란 버튼, 여기쯤 눌러"라며 마우스를 움직여요.

화면에 보이기만 하면 무엇이든 볼 수 있어요. 버튼 위치가 조금 바뀌면 헛누를 수 있어요.

vs
이름표 목록을 받는 친구 · agent-desktop

화면 대신 "1번: 저장 버튼, 2번: 닫기 버튼"이라고 적힌 목록을 받아 "1번 눌러"라고 말해요.

위치가 바뀌어도 이름으로 찾으니 정확해요. 이름표가 없는 버튼은 아예 못 봐요.

2

어떤 문제를 해결하나요?

사진을 보고 짐작해서 누르는 방식의 약점을, 이름표로 정확히 가리키는 방식으로 줄여요.

설명2-1. 사진 방식은 왜 자주 헛누를까요

사진 방식은 AI가 화면 사진에서 버튼 위치를 짐작해 좌표를 눌러요. 그래서 아래 경우에 잘못 누를 수 있어요.

  • 창 크기나 버튼 위치가 조금 바뀌었을 때
  • 화면이 아직 다 뜨지 않았을 때(로딩 중)
  • 글자가 작아서 사진을 줄였을 때 잘 안 보일 때

agent-desktop은 사진 대신 운영체제가 이미 알고 있는 '이 버튼의 이름은 저장, 종류는 버튼'이라는 정보를 읽어요. 그래서 좌표를 짐작하지 않고 번호로 가리켜요.

비교2-2. 클로드 컴퓨터 유즈와 나란히 놓고 보기

항목클로드 컴퓨터 유즈agent-desktop (Vercel Labs)
보는 방법스크린샷을 찍어서 봐요운영체제의 접근성 트리(버튼 이름표 목록)를 읽어요
누르는 방법화면 좌표를 클릭·타이핑·스크롤해요스냅샷 속 번호(ref)를 지정해 눌러요
쓰는 곳클로드 데스크톱 앱(macOS·Windows), 클로드 코드 CLI(macOS)터미널 명령어 도구라 클로드 코드 같은 코딩 에이전트가 불러 써요
설치따로 설치하지 않아요. 데스크톱 앱 [Settings] → [This computer] → [System]에서 켜거나, 클로드 코드에서 /mcp로 computer-use를 켜요npm 등으로 따로 설치해요
못 하는 것브라우저는 보기만 해요. 웹 작업은 클로드 인 크롬이 맡아요이름표가 없는 앱은 못 봐요. 웹 페이지 자동화는 agent-browser가 맡아요
비용Pro·Max 요금제에서 쓰는 리서치 프리뷰예요(Team·Enterprise 제외)도구는 무료예요. 이 도구를 부르는 AI(클로드 코드 등) 사용료는 따로 들어요

공식 확인: Claude Code 컴퓨터 유즈 문서 · agent-desktop README (2026.11.10 확인)

설명2-3. 실제로 체감되는 차이

차이 ①

어떤 앱이든 보이나요?

사진 방식은 화면에 보이기만 하면 일단 봐요. 이름표 방식은 앱이 이름표를 붙여 두지 않았으면 아예 못 봐요.

차이 ②

같은 일을 반복할 때

이름표 방식은 "저장 버튼"처럼 이름으로 찾아요. 그래서 같은 작업을 스크립트로 되풀이하기에 유리해요.

차이 ③

속도와 비용

사진보다 글자 목록이 AI가 읽을 양이 적어서 더 빠르고 쌀 가능성이 커요.

차이 ③은 일반적인 추정이에요. 두 도구를 같은 일로 직접 재 본 공식 자료는 아직 확인하지 못했어요.
3

조심할 점

공식 README에 적힌 한계와 주의 사항이에요.

한계3-1. 이름표가 없는 앱은 못 봐요

agent-desktop은 macOS에서는 AX API, Windows에서는 UI Automation, 리눅스에서는 AT-SPI라는 운영체제 기능으로 이름표를 읽어요. 앱이 이 이름표를 제대로 붙여 두지 않았으면 버튼이 목록에 나오지 않아요.

그런 앱은 사진 방식(컴퓨터 유즈)이 더 맞을 수 있어요. 하나만 고집하지 말고, 일에 맞게 골라요.

한계3-2. 번호는 스냅샷마다 새로 받아요

번호는 그 스냅샷에서만 통해요. 화면이 바뀌면 예전 번호는 '오래된 번호'라는 오류(STALE_REF)를 내요.

그래서 에이전트는 늘 스냅샷 → 번호로 누르기 → 다시 스냅샷으로 확인 순서로 일해요. 이 순서를 지키는지 결과를 볼 때 확인해요.

주의3-3. 내 화면 내용이 기록에 남아요

  • 스냅샷·클립보드·스크린샷에는 내 화면의 개인 정보가 들어갈 수 있어요. 공개 저장소나 단톡방에 그대로 올리지 않아요
  • macOS에서는 [손쉬운 사용](접근성) 권한을 줘야 동작해요. 이 권한은 앱을 대신 누를 수 있는 강한 권한이에요
  • 비밀번호처럼 민감한 입력은 실습에서 쓰지 않아요
4

써 볼까요?

클로드 코드에 agent-desktop을 붙이고, 맥 메모 앱에 셀렉트마켓 공지 메모를 하나 남겨요.

STEP 14-1. 설치하고 권한 주기

터미널을 열고 아래 세 줄을 한 줄씩 실행해요.

터미널
npm install -g agent-desktop
agent-desktop status
agent-desktop permissions --guide
설치 첫 줄은 agent-desktop을 내 컴퓨터에 설치해요. 홈브루를 쓰면 brew install agent-desktop으로도 설치할 수 있어요.
상태 확인 둘째 줄은 운영체제·권한·쓸 수 있는 기능을 보여 줘요.
권한 주기 셋째 줄은 맥 [시스템 설정] → [개인정보 보호 및 보안] → [손쉬운 사용]에서 권한을 주는 길을 안내해요.

확인할 점권한을 준 뒤 agent-desktop status를 다시 실행해 권한이 허용으로 바뀌었는지 봐요.

막히면npm이 없다는 오류가 나면 Node.js부터 설치해요. 설치 중 스크립트 승인을 묻는 경고가 나오면 README의 설치 안내를 따라요.

STEP 24-2. 클로드 코드에 스킬로 붙이기

클로드 코드가 agent-desktop 쓰는 법을 알도록 스킬을 추가해요.

터미널
npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop

확인할 점클로드 코드를 새로 열고 "agent-desktop 스킬 쓸 수 있어?"라고 물어 스킬을 알아보는지 봐요.

STEP 34-3. 메모 앱에 셀렉트마켓 공지 메모 남기기

클로드 코드에 아래 프롬프트를 붙여 넣어요. 클로드가 스냅샷을 찍고, 번호로 누르고, 다시 확인하는 과정을 지켜봐요.

프롬프트
요청: agent-desktop으로 맥의 메모 앱을 열고 새 메모를 하나 만들어 줘.
내용: 메모 첫 줄은 "셀렉트마켓 11월 공지", 둘째 줄은 "주말 배송은 월요일에 출고됩니다."로 써 줘. 이 두 줄 말고 다른 문장은 추가하지 마.
형식: 매번 스냅샷을 찍은 뒤 어떤 번호(ref)를 눌렀는지 한 줄씩 보여 주고, 마지막에 다시 스냅샷을 찍어 메모 내용이 맞는지 확인해 줘. 스크린샷은 쓰지 마.
  • 메모 앱에 두 줄짜리 새 메모가 생겼나요?
  • 클로드가 덧붙인 문장이 없나요?
  • 클로드가 '스냅샷 → 번호로 누르기 → 다시 스냅샷' 순서로 일했나요?
  • 스크린샷 없이 끝났나요?

막히면권한 오류가 나면 STEP 1의 권한 주기로 돌아가요. STALE_REF 오류가 나면 클로드에게 "스냅샷을 새로 찍고 다시 해 줘"라고 말해요.

AI의 손은 '보는 법'에 따라 잘하는 일이 달라요

② 사진 방식은 무엇이든 보지만 헛누를 수 있고, 이름표 방식은 정확하지만 이름표 없는 앱은 못 봐요.
