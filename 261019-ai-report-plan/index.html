생성형 AI로 문서 제작 워크플로우 만들기

먼저 모두 같은 ChatGPT 모델로 맞춰요. 그다음 내 업무를 스케치하고, 그 업무를 5가지 단계(파악 · 정리 · 요약 · 분석 · 보고)로 쪼개서 하나의 프로세스로 정의해 봐요. 이렇게 정의해 두면 AI에게 무엇을 어느 단계에서 부탁할지 분명해져요.

시작 전: ChatGPT 화면 살펴보고 모델 맞추기

실습을 시작하기 전에 ChatGPT 웹 화면에서 자주 쓰는 곳 네 군데를 확인하고, 모두 같은 모델로 맞춰요. 오늘 수업은 GPT-5.6 Sol · Instant로 맞춰서 진행해요. 모델이 다르면 같은 프롬프트를 보내도 답변 모양이 달라지고, 만든 파일이 시트 화면으로 열리지 않을 수 있어요.

번호이름하는 일
①새 채팅새 대화창을 열어요. 실습 주제가 바뀔 때 눌러요.
②입력창프롬프트를 붙여 넣고 Enter로 보내요.
③+ (파일 추가)실습 파일(CSV)을 첨부해요.
④모델·추론 수준 표시지금 쓰는 모델과 추론 수준이 보여요. 오늘은 여기에 5.6 Instant가 보여야 해요.

모델 확인하고 GPT-5.6 Sol · Instant로 맞추기

입력창 오른쪽 ④를 눌러요. 작은 창이 열리고 위에 현재 모델과 추론 수준이, 아래에 슬라이더가 보여요. 슬라이더가 맨 왼쪽에 있으면 Instant예요. 다른 위치라면 맨 왼쪽으로 옮겨요.
창 위쪽 글자 Ⓐ를 눌러 모델 목록을 열고 GPT-5.6 Sol을 골라요.
GPT-5.6 Sol을 누르고 나면, ④ 자리에 5.6 Instant라고 표시가 돼요.
모델과 Instant(추론 수준)는 무엇이 다른가요?
모델은 답을 만드는 AI 자체예요. GPT-6, GPT-5.6 Sol처럼 이름이 다르면 다른 AI예요. 자동차로 치면 차종이에요.
추론 수준은 같은 모델이 답하기 전에 얼마나 생각할지 정하는 설정이에요. 자동차로 치면 주행 모드예요. Instant는 오래 생각하지 않고 바로 답하는 가장 빠른 수준이에요. 수준을 높이면 답이 느려지는 대신 복잡한 문제를 더 꼼꼼히 풀어요.
오늘은 모두 같은 화면과 비슷한 답을 보기 위해 모델은 GPT-5.6 Sol, 추론 수준은 Instant로 맞춰요.

먼저, 워크플로우란?

오늘 수업 제목에 나오는 "워크플로우"라는 단어부터 풀어 볼게요.

워크플로우(workflow)는 일(work)이 흐르는(flow) 순서를 뜻해요. 일이 시작해서 끝나기까지 어떤 단계를 거치는지를 순서대로 나열한 거예요. 점심을 주문하는 일도 "메뉴 고르기 → 주문하기 → 결제하기 → 받기"라는 워크플로우가 있어요. 데이터 업무에도 같은 흐름이 있어요. "주문 파일 내려받기 → 정리하기 → 합계 구하기 → 비교하기 → 보고하기" 같은 순서예요.

"AI로 만드는 워크플로우"는 이 순서 중에서 어느 단계를 AI에게 맡기고, 어느 단계를 내가 직접 확인할지 정해 둔 흐름이에요. 이렇게 정해 두면 AI에게 무엇을 어느 단계에서 부탁할지 분명해져요. 오늘 보고서·기획서를 만들 때 쓰는 데이터 업무 워크플로우는 다섯 단계예요.

1파악어떤 데이터인지 훑어보기
2정리표기 통일, 중복·빈칸 처리
3요약기준별 합계 구하기
4분석비교하고 질문하기
5보고결과를 한 장으로 전달

"프로세스"라는 말도 자주 나와요. 프로세스는 일을 진행하는 방식과 절차를 뜻하고, 오늘은 워크플로우와 거의 같은 뜻으로 써요. 이제 내 업무로 이 워크플로우를 직접 만들어 볼게요.

STEP 1. 구글 시트 준비하기

버전 E의 STEP 1처럼 orders_clean.csv를 구글 시트로 가져와 열어요. 이미 만든 시트가 있으면 그 시트를 그대로 써요.
화면 아래쪽 시트 탭 이름을 더블클릭해서 orders로 바꿔요. 코드가 이 이름으로 데이터를 찾아요.

STEP 2. 시트에서 Apps Script 열기

시트 메뉴에서 [확장 프로그램] → [Apps Script]를 눌러요. 새 탭에 코드 편집기가 열리고, 왼쪽 파일 목록에 Code.gs가 하나 있어요. 이렇게 시트에서 연 스크립트는 그 시트와 연결돼 있어요.
왼쪽 위 "제목 없는 프로젝트"를 눌러 이름을 3분기 매출 웹 대시보드로 바꿔요.

STEP 3. ChatGPT로 코드 만들기

새 대화창에서 아래 프롬프트를 그대로 보내요. 열 이름과 계산 규칙을 알려 줘야 AI가 시트 구조를 짐작하지 않고 정확하게 만들어요.

프롬프트 · 복사해서 사용하세요
요청: 구글 Apps Script 웹 앱으로 휴대폰에서 보기 좋은 매출 대시보드 페이지 코드를 만들어 줘.
내용: 구글 시트의 [확장 프로그램 → Apps Script]에서 연 프로젝트야(시트에 연결된 스크립트). 데이터는 같은 스프레드시트의 'orders' 시트에 있고 1행이 제목이야. 열은 주문번호, 주문일, 월, 지역, 채널, 담당자, 상품코드, 수량, 단가, 금액, 결제상태, 집계대상, 비고야.
- 집계대상이 'Y'인 행만 집계해서 ① 총매출(금액 합계) ② 월별 매출(7·8·9월) ③ 지역별 매출(큰 순서)을 보여 줘.
- '월' 열은 날짜로 바뀌어 있을 수 있으니 '주문일' 기준으로 월을 계산해 줘.
- 집계는 Code.gs에서 끝내고 화면에는 숫자만 넘겨 줘. 페이지를 열 때마다 시트의 최신 값을 읽어야 해.

형식: Code.gs와 index.html 두 파일의 전체 코드. 휴대폰 세로 화면에 맞춘 카드형 디자인(가로 스크롤 없음, 큰 글씨), 외부 라이브러리 없이 HTML·CSS로 막대 표시, 금액은 1,234,000원 형식. 각 코드를 어느 파일에 붙여 넣는지도 알려 줘.

위쪽 저장 아이콘(또는 Ctrl+S, 맥은 ⌘+S)을 눌러 저장해요.

"유형 선택" 옆 톱니바퀴를 눌러 웹 앱을 골라요.
설명에 "3분기 매출 대시보드 v1"처럼 적고, 다음 사용자 인증 정보로 실행은 나, 액세스 권한이 있는 사용자는 모든 사용자로 골라요. [배포]를 눌러요.
처음 배포하면 [액세스 승인]을 누르고 내 구글 계정을 골라요. "Google에서 확인하지 않은 앱" 경고가 나오면 [고급] → [(프로젝트 이름)(으)로 이동]을 누르고 [허용]을 눌러요. 내가 직접 만든 스크립트라서 나오는 경고예요.
배포가 끝나면 나오는 웹 앱 URL을 복사해요. 이 주소가 대시보드 페이지예요.

관리자 설정에 따라 [모든 사용자]가 없고 "(회사 이름) 내 모든 사용자"만 보일 수 있어요. 그러면 회사 밖 사람은 이 페이지를 볼 수 없어요.
