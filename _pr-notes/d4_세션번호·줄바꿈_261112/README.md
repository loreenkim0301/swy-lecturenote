## 바뀐 점
1. 세션 번호
   - 'AI 서비스를 써 보고, 관리자가 프롬프트를 고칠 수 있게 만들기'를 SESSION 1로 바꿨어요. 이 세션은 원래 SESSION 0이었어요.
   - 뒤 세션은 하나씩 밀려서 SESSION 2부터 SESSION 6까지예요.
   - 세부 번호(0-1 → 1-1), 앵커(id/href), 본문 안 참조('1-5의 한도', '오후 4세션' 등)도 함께 바꿨어요.
   - '수요일 2-5'는 DAY 3을 가리키는 번호라서 그대로 뒀어요.
   - 남아 있던 오래된 참조('이벤트 정보를 2세션에서 써요')를 실제 쓰는 세션인 4세션으로 고쳤어요.
   - 3주차 홈의 DAY 4 링크를 #s2-1에서 #s3-1로 고쳤어요.
2. 줄바꿈 (3주차 전 페이지 CSS)
   - 원래 있던 단어 단위 끊기(keep-all)는 유지했어요.
   - 제목은 줄 길이를 고르게 맞췄어요(text-wrap: balance).
   - 본문은 마지막 줄에 한 단어만 남지 않게 했어요(text-wrap: pretty).
3. 의미 단위 묶기 (DAY 4, 홈 본문)
   - 함께 읽어야 하는 말은 줄바꿈 금지 공백으로 묶었어요. 예: '고칠 수 있게', '써 보고', '열어 둬요', '만들었던 것', '3 개'.
   - DAY 4에서 175곳, 홈에서 10곳을 묶었어요.
   - 코드와 프롬프트 복사 박스(pre)는 바꾸지 않았어요.
