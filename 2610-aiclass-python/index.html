기능어디서언제 쓰나

② 코드 설명 · 오류 설명셀의 Gemini 버튼, 에러 아래 "오류 설명" 버튼모르는 코드·에러가 나왔을 때 바로 질문

3. Part 1. 프로그래밍은 어떻게 동작하나

  • 입력 → 처리 → 출력: 키오스크 주문(입력) → 금액 계산(처리) → 영수증(출력)
  • 코드는 사람이 쓰고, 실행은 해석기가 함: Colab은 구글 서버에 파이썬 해석기가 미리 설치된 환경
  • 위에서 아래로, 순서대로: 순서가 곧 로직
price = int(input("상품 가격(원): "))   # 입력
total = price * 1.1                    # 처리 (부가세 10%)
print("결제 금액:", int(total), "원")   # 출력

AI 활용: 실행 후 Gemini에게 "이 코드를 한 줄씩 비유로 설명해 줘" → 내 이해와 비교

PM 포인트: 기획서의 "사용자가 ○○하면 △△가 보인다"가 입력·처리·출력입니다. 규칙이 모호하면 개발자도 AI도 추측합니다.

6. Part 4. 기타: 오류 검증 · 웹과의 관계

4-1. 오류의 3가지 종류

종류뜻예시AI가 잘 잡나?
문법 오류문장 자체가 틀림괄호 누락, 들여쓰기잘 잡음
실행 오류실행 중 멈춤문자열 + 숫자잘 잡음
논리 오류멈추지 않지만 결과가 틀림>= 와 > 실수못 잡음. 기대값을 아는 사람만 잡을 수 있음

4-2. 실습: 세 가지 오류 직접 내고 해결하기

  1. 일부러 에러 내기: print("가격:" + 15000)
  2. 에러 메시지 맨 아래 줄 읽기 → Colab "오류 설명" 버튼으로 Gemini 설명 보기
  3. 같은 에러를 ChatGPT에 붙여넣고 설명 비교
  4. 논리 오류는 AI가 모름 → 기대값 테스트로 직접 잡기
def pay(price):              # 3만원 이상이면 10% 할인
    if price > 30000:        # 일부러 넣은 버그
        return price * 0.9
    return price

assert pay(20000) == 20000
assert pay(40000) == 36000
assert pay(30000) == 27000   # 경계값 → 실패!

4-4. 파이썬으로 웹사이트를 바로 만들 수 없는 이유

HTML / CSS / JS파이썬
어디서 실행되나사용자의 브라우저내 컴퓨터, Colab, 서버
역할화면계산·데이터 처리·자동화·서버 로직
  • 브라우저는 HTML·CSS·JS만 알아듣습니다. 파이썬으로 웹을 만들려면 웹 프레임워크(Flask, Django, Streamlit 등)로 서버를 띄우고 배포까지 해야 합니다.
