2. 파트별 핵심 실습 코드

Part 1. 첫 실행

print("안녕, 파이썬")
print(1 + 2)

Part 2. 변수와 입력

name = input("이름이 뭐예요? ")
age = int(input("나이는요? "))
print(name, "님은 내년에", age + 1, "살이 됩니다.")
예상 질문: int()를 빼면? → TypeError 발생. Part 3 디버깅 소재로 재활용.

Part 3. ChatGPT 질문 템플릿

나는 파이썬 왕초보야. Google Colab에서 아래 코드를 실행했어.
[코드 붙여넣기]
이런 에러가 났어.
[에러 메시지 전체 붙여넣기]
1) 왜 에러가 났는지 쉽게 설명해줘
2) 고친 코드를 보여줘
3) 다음에 같은 실수를 안 하려면 뭘 기억하면 돼?
원칙: 고친 코드를 받으면 직접 타이핑해서 실행. 복붙만 하면 배운 게 남지 않음.

Part 4. 조건문·반복문

score = int(input("점수: "))
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("다음엔 더 잘할 거예요")

for i in range(1, 10):
    print("2 x", i, "=", 2 * i)

Part 5. 미니 프로젝트

import random
menus = ["김치찌개", "돈까스", "쌀국수", "비빔밥"]
print("오늘 점심은", random.choice(menus), "!")

확장 미션(ChatGPT에게 물어서 해결): 메뉴 직접 추가하기 / 3번 추천받기 / 싫은 메뉴 제외하기
