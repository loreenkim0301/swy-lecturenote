2. Part 1. 프로그래밍은 어떻게 동작하나

한 줄 정의: 프로그래밍은 컴퓨터에게 순서대로 실행할 지시문을 써 주는 일입니다. 컴퓨터는 눈치를 보지 않고, 쓰인 그대로 위에서 아래로 실행합니다.
  • 입력 → 처리 → 출력: 키오스크 주문(입력) → 금액 계산(처리) → 영수증(출력)
  • 코드는 사람이 쓰는 글, 실행은 해석기가 함: 파이썬 코드는 "파이썬 해석기"가 읽어서 실행합니다. Colab은 구글 서버에 이 해석기가 이미 설치된 환경이라 설치 없이 바로 쓸 수 있습니다.
  • 순서가 곧 로직: 순서를 바꾸면 결과도 달라집니다.
# 실습 1: 입력 → 처리 → 출력
price = int(input("상품 가격(원): "))   # 입력
total = price * 1.1                    # 처리 (부가세 10%)
print("결제 금액:", int(total), "원")   # 출력
PM 포인트: 기획서의 "사용자가 ○○하면 △△가 보인다"는 문장이 바로 입력·처리·출력입니다. 처리 규칙이 모호하면 개발자도 AI도 추측해서 만듭니다.

3. Part 2. 파이썬으로 웹사이트를 바로 만들 수 없는 이유

HTML / CSS / JS파이썬
어디서 실행되나사용자의 브라우저내 컴퓨터, Colab, 서버
역할화면 (구조·디자인·움직임)계산·데이터 처리·자동화·서버 로직
파일을 열면더블클릭하면 브라우저에 바로 보임해석기가 실행할 뿐, 화면은 따로 만들어야 함
  • 브라우저는 HTML·CSS·JS만 알아듣습니다. 파이썬 코드를 브라우저에 그대로 주면 실행되지 않습니다.
  • 파이썬으로 웹을 만들려면 웹 프레임워크(Flask, Django, Streamlit 등)를 써서 서버를 띄우고, 서버가 HTML을 만들어 보내 줘야 합니다. 그 서버를 인터넷에 올리는 배포도 따로 해야 합니다.
  • 비유: HTML은 매장 진열대, 파이썬은 주방. 손님(브라우저)은 진열대만 보고, 주방은 뒤에서 음식을 만들어 내보냅니다.
PM 포인트: "화면 시안만 빨리" → HTML/CSS 프로토타입. "데이터 계산·자동화" → 파이썬. "로그인·저장이 되는 서비스" → 서버와 DB가 필요하므로 일정과 비용이 커집니다.

실습 2: 파이썬으로 먼저 로직 만들기

import random
products = [                       # 리스트
    {"name": "텀블러", "price": 15000, "stock": 3},
    {"name": "에코백", "price": 9000,  "stock": 0},
    {"name": "머그컵", "price": 12000, "stock": 5},
]
for p in products:                 # 반복
    if p["stock"] == 0:            # 조건
        label = "품절"
    else:
        label = f'{p["price"]:,}원'
    print(p["name"], "-", label)

print("오늘의 추천:", random.choice(products)["name"])   # random

5. Part 4. 오류는 어떻게 확인하나

오류의 3가지 종류

종류뜻예시찾기 난이도
문법 오류문장 자체가 틀림 (실행 전에 멈춤)괄호 누락, 들여쓰기 오류쉬움
실행 오류실행하다가 멈춤문자열 + 숫자, 없는 항목 찾기보통
논리 오류멈추지 않지만 결과가 틀림할인 계산 순서 잘못, 조건 경계값(>= vs >) 실수어려움, 가장 위험

검증 3단계

  1. 에러 메시지 맨 아래 줄부터 읽기: 에러 이름(TypeError 등)과 줄 번호가 있습니다.
  2. 중간값 출력하기: print()로 값이 내 예상과 같은지 확인합니다.
  3. 기대값으로 테스트하기: "이 입력이면 이 결과가 나와야 한다"를 미리 정하고 비교합니다. 기획서의 인수 조건과 같은 개념입니다.
# 논리 오류 찾기 실습: 3만원 이상이면 10% 할인
def pay(price):
    if price > 30000:          # 일부러 넣은 버그
        return price * 0.9
    return price

assert pay(20000) == 20000
assert pay(40000) == 36000
assert pay(30000) == 27000     # 경계값 테스트 → 여기서 실패!

# 실습 4: 가상의 주문 데이터 분석
import pandas as pd
df = pd.DataFrame({
    "채널": ["앱", "웹", "앱", "매장", "웹", "앱"],
    "상품": ["텀블러", "에코백", "머그컵", "텀블러", "텀블러", "에코백"],
    "매출": [150000, 90000, 120000, 300000, 45000, 60000],
})
print(df[df["매출"] >= 100000])          # 조건: 10만원 이상 주문만
print(df.groupby("채널")["매출"].sum())   # 채널별 매출 합계
df.groupby("채널")["매출"].sum().plot(kind="bar")   # 차트
PM 포인트: 코드를 직접 다 짜지 않아도 됩니다. "채널별 매출 합계를 막대그래프로" 같이 무엇을 어떤 기준으로 묶을지를 정확히 말하면 ChatGPT가 코드를 써 줍니다. 그다음 결과가 상식에 맞는지 검증하는 것이 PM의 일입니다.
