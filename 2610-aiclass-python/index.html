2. Part 0. Colab과 AI 도구 이해하기

오늘 수업의 모든 실습은 Google Colab에서 진행합니다. 처음 보는 도구라서 낯설 수 있지만, 꼭 필요한 개념은 몇 가지뿐입니다. 이 파트에서는 Colab이 무엇인지, 화면의 기본 단위가 어떤 역할을 하는지, 그리고 Colab 안에 들어 있는 AI와 ChatGPT를 어떻게 함께 쓸지를 정리합니다.

0-1. Colab이란 무엇인가

Colab(정식 이름 Colaboratory)은 구글이 만든 온라인 코드 실행 노트입니다. 원래 구글 리서치 팀이 연구자들을 위해 만들었고, 2017년에 일반 사용자에게 공개되었습니다. 파이썬 코드를 내 컴퓨터가 아니라 구글의 서버에서 실행해 주기 때문에, 브라우저만 있으면 설치 없이 바로 코딩을 시작할 수 있습니다. 구글 문서처럼 구글 드라이브에 자동 저장되고, 링크로 공유할 수도 있습니다.

항목내용
만든 곳Google (Google Research)
요금기본 무료. 구글 계정만 있으면 사용 가능. 더 좋은 컴퓨터 자원과 긴 실행 시간이 필요한 사람을 위한 유료 요금제(Colab Pro 등)가 따로 있음. 이 수업은 무료로 충분함
저장 위치내 구글 드라이브의 "Colab Notebooks" 폴더
기반 기술데이터 분석가들이 널리 쓰는 "주피터 노트북(Jupyter Notebook)"을 웹에서 쓸 수 있게 만든 것
유료 요금제의 가격과 구성은 자주 바뀌므로, 수강생이 물어보면 Colab 요금 안내 페이지에서 최신 정보를 함께 확인합니다.

0-2. 노트, 코드 셀, 텍스트 셀은 무슨 역할인가

Colab 파일 하나를 노트(노트북)라고 부릅니다. 노트는 칸(셀)들이 위에서 아래로 쌓인 문서입니다. 칸에는 두 종류가 있는데, 컴퓨터에게 시키는 일을 적는 코드 셀과 사람이 읽을 설명을 적는 텍스트 셀입니다. 이렇게 나누어 두는 이유는, 코드와 그 코드의 의도·결과 해석을 한 문서 안에서 함께 남길 수 있기 때문입니다. 나중에 내가 다시 보거나 동료에게 공유했을 때 "무엇을 왜 했는지"가 함께 전달됩니다.

구성 요소역할왜 필요한가
노트코드, 설명, 실행 결과를 한 파일에 담는 문서작업 과정 전체를 하나의 기록으로 남기고 공유할 수 있음. 기획서 한 장에 근거와 결론이 같이 있는 것과 비슷함
코드 셀컴퓨터에게 시킬 일을 적는 칸. 실행하면 결과가 칸 바로 아래에 나타남한 번에 전체를 실행하지 않고 한 칸씩 실행하고 확인할 수 있어서, 어디서 문제가 생겼는지 찾기 쉬움
텍스트 셀사람이 읽는 메모·설명을 적는 칸. 실행되지 않음코드의 의도, 결과 해석, 다음 할 일을 기록. 과제 정리도 여기에 함
런타임코드를 실제로 실행해 주는 구글 서버와의 연결오래 쓰지 않으면 연결이 끊기고 기억하던 값이 사라짐. 그럴 때는 위에서부터 다시 실행하면 됨
기본 조작은 두 가지만 기억하세요. 코드 셀을 실행할 때는 셀 왼쪽의 ▶ 버튼을 누르거나 Shift+Enter를 누릅니다. 노트를 공유할 때는 오른쪽 위 "공유"를 누릅니다.

0-3. Colab 속 AI: Gemini

Colab에는 구글의 생성형 AI인 Gemini가 들어 있습니다. 따로 사이트를 열지 않아도, 지금 보고 있는 노트의 코드와 오류를 AI가 직접 읽고 설명하거나 고쳐 줍니다. 이 기능은 한 번에 생긴 것이 아니라 몇 단계에 걸쳐 확대되었습니다.

0-4. ChatGPT와 함께 쓸 때 알아야 할 것

이 수업에서는 Colab 안의 Gemini와 별도 창의 ChatGPT, 두 개의 AI를 함께 씁니다. Gemini는 지금 노트의 코드와 오류를 직접 보고 답할 수 있다는 장점이 있고, ChatGPT는 개념을 쉬운 말로 풀어 설명받거나, 다른 관점에서 다시 확인할 때 유용합니다. 다만 두 AI를 쓰면 같은 질문에도 서로 다른 답이 나올 수 있다는 점을 미리 알아 두어야 합니다.

  • 답이 다를 수 있는 이유: 둘 다 생성형 AI이기 때문입니다. 생성형 AI는 정해진 정답을 찾아오는 것이 아니라, 그때그때 그럴듯한 답을 새로 만들어 냅니다. 그래서 AI가 다르면 답이 다르고, 같은 AI에게 같은 질문을 다시 해도 답이 달라질 수 있습니다.
  • AI도 실수합니다: 문법은 맞지만 결과가 틀린 코드를 자신 있게 내놓기도 합니다. 그래서 AI가 준 코드는 반드시 실행해서 결과를 직접 확인해야 합니다.
  • 같은 대화 안에서 검증하면 AI는 자기 답을 옹호하는 경향이 있습니다: 코드를 만들어 준 그 대화창에 "이거 맞아?"라고 물으면, AI는 앞서 자신이 한 답에 맞춰 "맞다"고 하기 쉽습니다. 검토를 맡길 때는 새 대화창을 열거나 다른 AI에게 물어보는 것이 좋습니다.

검증 원칙: 두 AI의 답이 다르면 그 차이 자체가 좋은 질문거리입니다. 최종 판단은 AI가 아니라 실행 결과와 내가 기대한 값을 비교해서 내립니다.

3. Part 1. 프로그래밍은 어떻게 동작하나

프로그래밍은 컴퓨터에게 할 일을 순서대로 적어 주는 일입니다. 컴퓨터는 눈치를 보거나 빠진 부분을 알아서 채우지 않고, 적힌 그대로 위에서 아래로 한 줄씩 실행합니다. 거의 모든 프로그램은 무언가를 받아서(입력), 정해진 규칙대로 계산하고(처리), 결과를 보여주는(출력) 구조로 되어 있습니다. 키오스크에서 메뉴를 고르면(입력) 금액이 계산되고(처리) 영수증이 나오는(출력) 것과 같습니다.

우리가 쓰는 코드는 사람이 읽을 수 있는 글입니다. 이 글을 컴퓨터가 알아듣도록 읽고 실행해 주는 프로그램을 해석기라고 부릅니다. Colab은 구글 서버에 이 해석기가 이미 준비되어 있는 환경입니다.

price = int(input("상품 가격(원): "))   # 입력
total = price * 1.1                    # 처리 (부가세 10%)
print("결제 금액:", int(total), "원")   # 출력
  • 해 보기: 실행한 뒤 가격을 바꿔 넣어 보고, 셋째 줄과 둘째 줄의 순서를 바꾸면 어떻게 되는지 확인합니다.
  • AI 활용: Gemini에게 "이 코드를 한 줄씩 비유로 설명해 줘"라고 요청해 내 이해와 비교합니다.
PM 포인트: 기획서의 "사용자가 ○○하면 △△가 보인다"라는 문장이 곧 입력·처리·출력입니다. 처리 규칙이 모호하면 개발자도 AI도 추측해서 만듭니다.

4. Part 2. 파이썬은 무엇인가

파이썬은 1991년 네덜란드의 프로그래머 귀도 반 로섬이 발표한 프로그래밍 언어입니다. 문법이 영어 문장에 가깝고 간결해서 처음 배우는 사람에게 가장 많이 권하는 언어 중 하나이고, 동시에 데이터 분석, 업무 자동화, 인공지능 개발 같은 실무 현장에서도 가장 널리 쓰이는 언어입니다. 쉽게 시작할 수 있으면서 실무에서도 바로 쓰인다는 점이 파이썬의 가장 큰 특징입니다.

오늘 수업은 어렵게 하지 않습니다. 보통 개발자들은 파이썬을 배울 때 내 컴퓨터에 파이썬을 설치하고, 코드 편집 프로그램을 깔고, 여러 설정을 맞추는 것부터 시작합니다. 이 과정에서 많은 입문자가 첫 코드도 실행해 보기 전에 지칩니다. 우리는 이 과정을 하지 않아도 됩니다. Colab에 이미 모든 준비가 되어 있기 때문에, 브라우저를 열고 바로 코드를 실행합니다.

5. Part 3. 기초 문법 맛보기

이 파트에서는 개념 설명을 먼저 듣지 않고, 코드를 먼저 실행해 본 다음 방금 무슨 일이 일어났는지를 이해하는 순서로 진행합니다. 직접 결과를 본 뒤에 이름을 붙이면 훨씬 쉽게 기억에 남습니다. 각 문법마다 코드를 타이핑해서 실행하고, 값을 하나 바꿔 다시 실행해 본 뒤, 개념 설명을 읽습니다. 이해가 안 되는 부분은 Gemini에게 "왜 이렇게 나와?"라고 물어봅니다.

3-1. 변수

먼저 아래 코드를 실행하고, qty의 값을 5로 바꿔 다시 실행해 보세요.

product = "텀블러"
price = 15000
qty = 3
print(product, price * qty, "원")

방금 무슨 일이 일어났나: price = 15000은 15000이라는 값에 price라는 이름표를 붙여 저장한 것입니다. 이렇게 값에 이름을 붙여 저장해 두는 것을 변수라고 합니다. 한 번 저장해 두면 이름만으로 값을 다시 쓸 수 있고, 값을 바꾸면 그 이름을 쓰는 모든 계산 결과가 함께 바뀝니다.

3-2. 조건

실행한 뒤 stock을 3, 10으로 바꿔 가며 결과를 비교해 보세요.

stock = 0
if stock == 0:
    print("품절")
elif stock < 5:
    print("품절 임박")
else:
    print("구매 가능")

방금 무슨 일이 일어났나: 값에 따라 다른 문장이 출력되었습니다. "만약 ~라면 이렇게, 아니면 저렇게"처럼 상황에 따라 다른 행동을 하게 만드는 것을 조건문이라고 합니다. if 아래 줄이 안쪽으로 들어가 있는 것(들여쓰기)은 "이 조건일 때 실행할 부분"이라는 표시입니다.

3-3. 리스트

menus = ["김치찌개", "돈까스", "쌀국수"]
print(menus[0])
menus.append("비빔밥")
print(len(menus), menus)

방금 무슨 일이 일어났나: 여러 개의 값을 대괄호 안에 순서대로 묶어 하나의 이름으로 저장했습니다. 이것을 리스트라고 합니다. menus[0]이 첫 번째 값인 이유는 파이썬이 순서를 0부터 세기 때문입니다. append로 항목을 추가하고 len으로 개수를 셀 수 있습니다.

3-4. 반복

prices = [15000, 9000, 12000]
for p in prices:
    print(p, "원의 할인가는", int(p * 0.9), "원")

방금 무슨 일이 일어났나: 코드는 한 번만 썼는데 결과는 세 줄이 나왔습니다. 리스트에 든 값을 하나씩 꺼내 같은 일을 되풀이하게 하는 것을 반복문이라고 합니다. 상품이 3개든 3,000개든 코드는 그대로입니다.

3-5. random

아래 코드를 여러 번 실행해 보세요. 실행할 때마다 결과가 달라지는지 확인합니다.

import random
print("오늘 점심은", random.choice(menus))

방금 무슨 일이 일어났나: import random은 파이썬에 미리 만들어져 있는 "무작위 기능 묶음"을 불러온 것입니다. random.choice는 리스트에서 하나를 무작위로 고릅니다. 이렇게 남이 만들어 둔 기능 묶음을 불러와 쓰는 방식은 Part 4의 데이터 분석에서도 똑같이 쓰입니다.

3-6. 종합하고 AI로 확장하기

지금까지의 다섯 가지를 한 번에 써 보면 상품 목록 화면의 로직이 됩니다. 실행한 뒤, Gemini 코드 생성에 말로 기능을 추가해 달라고 요청해 보세요.

import random
products = [
    {"name": "텀블러", "price": 15000, "stock": 3},
    {"name": "에코백", "price": 9000,  "stock": 0},
    {"name": "머그컵", "price": 12000, "stock": 5},
]
for p in products:
    if p["stock"] == 0:
        print(p["name"], "- 품절")
    else:
        print(p["name"], "-", f'{p["price"]:,}원')
print("오늘의 추천:", random.choice(products)["name"])
  • Gemini 요청 예시: "품절 상품은 오늘의 추천에서 빼 줘"
  • 검증: 여러 번 실행해서 에코백이 추천에 한 번도 나오지 않는지 확인합니다.
PM 포인트: 화면 기획의 대부분은 데이터(리스트), 규칙(조건), 반복으로 이루어집니다. 이 단어로 요구사항을 말하면 개발자도 AI도 정확하게 알아듣습니다.

6. Part 4. 데이터 분석 맛보기

데이터 분석 현장에서는 파이썬이 사실상 표준 도구로 쓰입니다. 그렇다면 왜 웹을 만드는 HTML, CSS, 자바스크립트가 아니라 파이썬일까요? 먼저 그 이유를 짚고, 같은 기초 문법이 데이터 분석에서 어떻게 쓰이는지 직접 실행해 본 뒤, Gemini에게 분석을 맡기고 결과를 검증해 봅니다.

4-1. 왜 데이터 분석에는 파이썬을 쓰는가

HTML과 CSS는 화면의 구조와 모양을 정하는 언어여서 계산을 하거나 데이터를 처리할 수 없습니다. 자바스크립트는 계산을 할 수 있지만, 주로 브라우저 안에서 화면을 움직이기 위해 발전해 온 언어라서 대용량 데이터를 다루는 도구가 상대적으로 부족합니다. 파이썬은 오랜 기간 연구자와 분석가들이 데이터를 다루는 도구를 만들고 공유해 온 덕분에, 표 데이터 처리, 통계, 차트, 머신러닝에 필요한 도구가 가장 풍부하게 갖춰져 있습니다.

HTML / CSS자바스크립트파이썬
본래 목적화면 구조와 디자인브라우저 화면의 동작범용 프로그래밍, 데이터 처리
계산·데이터 처리불가능가능하지만 분석 도구가 적음가능, 분석 도구가 가장 풍부
대표 분석 도구없음일부 차트 도구pandas(표), matplotlib(차트), scikit-learn(머신러닝)
실행 위치브라우저주로 브라우저내 컴퓨터, 서버, Colab
정리: 화면은 HTML·CSS·자바스크립트, 데이터 분석은 파이썬. 서로 잘하는 일이 다릅니다.

7. Part 5. 기타: 오류 검증 · 웹과의 관계

마지막 파트에서는 두 가지를 정리합니다. 첫째, 코드가 틀렸을 때 그것을 어떻게 알아차리고 확인할 것인가입니다. AI가 코드를 대신 써 주는 시대일수록 이 능력이 더 중요해집니다. 둘째, 오늘 배운 파이썬으로 왜 웹사이트를 바로 만들 수는 없는지입니다.

5-1. 오류의 3가지 종류

오류는 크게 세 종류로 나뉩니다. 앞의 두 가지는 빨간 에러 메시지가 나오기 때문에 쉽게 알아챌 수 있고, AI도 잘 고칩니다. 가장 위험한 것은 세 번째인 논리 오류입니다. 에러 없이 실행되지만 결과가 틀리기 때문에, "원래 어떤 결과가 나와야 하는지" 아는 사람만 잡아낼 수 있습니다.

종류뜻예시AI가 잘 잡나?
문법 오류문장 자체가 틀려 실행 전에 멈춤괄호 누락, 들여쓰기 오류잘 잡음
실행 오류실행하다가 멈춤문자열과 숫자를 더함잘 잡음
논리 오류멈추지 않지만 결과가 틀림"이상"을 "초과"로 잘못 씀잘 못 잡음. 기대값을 아는 사람이 잡아야 함

5-2. 실습: 오류를 직접 내고 해결하기

먼저 일부러 실행 오류를 내고, Colab Gemini와 ChatGPT의 설명을 비교해 봅니다. 그다음 논리 오류는 AI가 아니라 기대값 테스트로 직접 잡아 봅니다.

  1. print("가격:" + 15000)을 실행해 에러를 냅니다.
  2. 에러 메시지의 맨 아래 줄을 먼저 읽습니다. 에러 이름과 원인이 적혀 있습니다.
  3. Colab의 "오류 설명" 버튼을 눌러 Gemini의 설명을 봅니다.
  4. 같은 코드와 에러를 ChatGPT에 붙여넣고 두 설명을 비교합니다.
  5. 아래 논리 오류 코드를 실행하고, 어떤 테스트가 실패하는지 확인합니다.
def pay(price):              # 규칙: 3만원 이상이면 10% 할인
    if price > 30000:        # 일부러 넣은 버그
        return price * 0.9
    return price

assert pay(20000) == 20000
assert pay(40000) == 36000
assert pay(30000) == 27000   # 경계값 테스트에서 실패

assert는 "이 결과가 나와야 한다"고 미리 적어 두고, 다르면 멈추게 하는 확인 장치입니다. 기획서의 인수 조건(이 경우엔 이렇게 되어야 한다)과 같은 개념입니다.

5-3. ChatGPT 질문 템플릿

AI에게 오류를 물을 때는 코드, 기대한 결과, 실제 결과를 함께 주어야 정확한 답을 받을 수 있습니다. 검토를 맡길 때는 코드를 만든 대화창이 아니라 새 대화창에서 묻습니다.

5-4. 파이썬으로 웹사이트를 바로 만들 수 없는 이유

우리가 웹사이트를 볼 때 쓰는 브라우저는 HTML, CSS, 자바스크립트만 알아듣습니다. 파이썬 코드를 브라우저에 그대로 주면 실행되지 않습니다. 파이썬은 브라우저가 아니라 서버나 내 컴퓨터에서 실행되는 언어이기 때문입니다. 파이썬으로 웹 서비스를 만들려면 웹 프레임워크(Flask, Django, Streamlit 등)로 서버를 만들고, 그 서버가 HTML을 만들어 브라우저에 보내도록 해야 하며, 그 서버를 인터넷에 올리는 배포 작업도 따로 필요합니다.

HTML / CSS / 자바스크립트파이썬
어디서 실행되나사용자의 브라우저내 컴퓨터, Colab, 서버
역할화면계산, 데이터 처리, 자동화, 서버 로직
비유: HTML은 매장의 진열대, 파이썬은 주방입니다. 손님(브라우저)은 진열대만 보고, 주방은 뒤에서 음식을 만들어 내보냅니다. 오늘 배운 변수·조건·반복·리스트·random은 자바스크립트에도 똑같이 있어서, 화면 프로토타입을 AI에게 요청할 때도 같은 단어로 말하면 됩니다.
