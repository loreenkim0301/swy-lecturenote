2. Part 1. 프로그래밍은 어떻게 동작하나

한 줄 정의: 프로그래밍은 컴퓨터에게 순서대로 실행할 지시문을 써 주는 일입니다. 컴퓨터는 눈치를 보지 않고, 쓰인 그대로 위에서 아래로 실행합니다.
  • 입력 → 처리 → 출력: 키오스크 주문(입력) → 금액 계산(처리) → 영수증(출력)
  • 코드는 사람이 쓰는 글, 실행은 해석기가 함: Colab은 구글 서버에 파이썬 해석기가 이미 설치된 환경이라 설치 없이 바로 쓸 수 있습니다.
  • 순서가 곧 로직: 순서를 바꾸면 결과도 달라집니다.
price = int(input("상품 가격(원): "))   # 입력
total = price * 1.1                    # 처리 (부가세 10%)
print("결제 금액:", int(total), "원")   # 출력
PM 포인트: 기획서의 "사용자가 ○○하면 △△가 보인다"가 바로 입력·처리·출력입니다. 처리 규칙이 모호하면 개발자도 AI도 추측해서 만듭니다.

3. Part 2. 기초 문법 맛보기

개념마다 ① 코드 읽기 ② 직접 타이핑 ③ 실행 ④ 값 하나 바꿔서 다시 실행.

2-1. 변수: 값에 이름 붙이기

product = "텀블러"
price = 15000
qty = 3
print(product, price * qty, "원")

2-2. 조건: 규칙에 따라 다르게

stock = 0
if stock == 0:
    print("품절")
elif stock < 5:
    print("품절 임박")
else:
    print("구매 가능")

2-3. 리스트: 여러 값을 한 줄에

menus = ["김치찌개", "돈까스", "쌀국수"]
print(menus[0])        # 첫 번째 (0부터 셈!)
menus.append("비빔밥")
print(len(menus), menus)

2-4. 반복: 같은 일을 여러 번

prices = [15000, 9000, 12000]
for p in prices:
    print(p, "원 → 할인가", int(p * 0.9), "원")

2-5. random: 매번 다른 결과

import random
print("오늘 점심은", random.choice(menus))

종합: 5가지를 한 번에

import random
products = [
    {"name": "텀블러", "price": 15000, "stock": 3},
    {"name": "에코백", "price": 9000,  "stock": 0},
    {"name": "머그컵", "price": 12000, "stock": 5},
]
for p in products:
    if p["stock"] == 0:
        print(p["name"], "- 품절")
    else:
        print(p["name"], "-", f'{p["price"]:,}원')
print("오늘의 추천:", random.choice(products)["name"])
PM 포인트: 화면 기획의 대부분은 데이터(리스트) + 규칙(조건) + 반복입니다. "상품 목록을 보여주고, 재고 0이면 품절 표시"라는 요구사항은 위 코드와 같은 구조입니다.

import pandas as pd
url = "https://loreenkim0301.github.io/swy-lecturenote/2610-aiclass-python/homework/04_orders.csv"

5. Part 4. 기타: 오류 검증 · 웹과의 관계

4-1. 오류의 3가지 종류

종류뜻예시찾기 난이도
문법 오류문장 자체가 틀림 (실행 전에 멈춤)괄호 누락, 들여쓰기 오류쉬움
실행 오류실행하다가 멈춤문자열 + 숫자, 없는 항목 찾기보통
논리 오류멈추지 않지만 결과가 틀림조건 경계값(>= vs >) 실수어려움, 가장 위험

4-2. 검증 3단계

  1. 에러 메시지 맨 아래 줄부터 읽기: 에러 이름과 줄 번호 확인
  2. 중간값 출력하기: print()로 값이 예상과 같은지 확인
  3. 기대값으로 테스트하기: "이 입력이면 이 결과"를 미리 정하고 assert로 비교. 기획서의 인수 조건과 같은 개념
def pay(price):              # 3만원 이상이면 10% 할인
    if price > 30000:        # 일부러 넣은 버그
        return price * 0.9
    return price

assert pay(20000) == 20000
assert pay(40000) == 36000
assert pay(30000) == 27000   # 경계값 → 여기서 실패!

4-3. AI로 오류 해결하기: ChatGPT와 Colab 내장 AI

  • Colab: 2026년 현재 Colab에는 Gemini 기반 AI 기능이 들어 있어, 에러가 나면 셀 아래에서 원인 설명과 수정안을 바로 제안받을 수 있습니다. (메뉴 위치·명칭은 수업 직전 실제 화면으로 재확인)
  • ChatGPT: 무료 플랜으로 충분합니다. 다만 파일 업로드 횟수 등에 제한이 있으니 수업 중에는 코드와 에러를 텍스트로 붙여넣는 방식을 기본으로 합니다.
나는 코딩을 잘 모르는 PM이야. Google Colab에서 아래 코드를 실행했어.
[코드]
기대한 결과: [예: 30000원이면 27000원]

1) 원인을 비유로 쉽게 설명해줘
2) 고친 코드를 보여줘
3) 고친 게 맞는지 확인할 테스트 케이스도 3개 줘
원칙: AI 답변도 검증 대상입니다. 고친 코드를 받으면 반드시 실행하고 기대값 테스트를 통과하는지 확인하세요. "돌아간다"와 "맞다"는 다릅니다.

4-4. 파이썬으로 웹사이트를 바로 만들 수 없는 이유

HTML / CSS / JS파이썬
어디서 실행되나사용자의 브라우저내 컴퓨터, Colab, 서버
역할화면 (구조·디자인·움직임)계산·데이터 처리·자동화·서버 로직
  • 브라우저는 HTML·CSS·JS만 알아듣습니다. 파이썬으로 웹을 만들려면 웹 프레임워크(Flask, Django, Streamlit 등)로 서버를 띄우고, 서버를 인터넷에 올리는 배포까지 해야 합니다.
  • 비유: HTML은 매장 진열대, 파이썬은 주방. 손님(브라우저)은 진열대만 보고, 주방은 뒤에서 음식을 만들어 내보냅니다.
  • Part 2에서 배운 변수·조건·반복·리스트·random은 JS에도 똑같이 있습니다. 화면 프로토타입을 AI에게 요청할 때 "상품 목록을 배열로, 재고 0이면 품절 배지, 카드는 반복으로"처럼 이 단어로 말하면 결과가 정확해집니다.
